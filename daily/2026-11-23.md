### 🌌 用双组分玻色—爱因斯坦凝聚体模拟 2+1 维有质量相对论量子场：看到可调质量隙的相对论色散与绕转 2π 的拓扑畴壁
**Analogue simulation of massive relativistic quantum fields in 2 + 1 dimensions**
*Nature (2026)*

量子场论是连接高能物理、宇宙学与凝聚态的基本语言，但**非微扰与动力学区间的求解极难**，空间维度超过一维时尤其如此。作者用**均匀二维原子玻色—爱因斯坦凝聚体中两个相干耦合的自旋分量**做模拟器：把两分量**相对相位 φ** 的长波模式编码成典范的**正弦—戈尔登（sine-Gordon）模型**。在微扰区，集体场激发表现出**带可调质量隙的相对论色散**；在非微扰区则直接观测到**拓扑畴壁**——φ 在畴壁处快速绕转 **2π**。这为预热（preheating）、拓扑缺陷动力学与相对论性**假真空衰变**等宇宙学相关过程提供了可调的实验平台。

📎 DOI: [10.1038/s41586-026-11268-y](https://doi.org/10.1038/s41586-026-11268-y)

### 🔲 石墨烯两侧分别对齐块体与单层 hBN：栅压/磁场/温度触发全局结构相变，掺杂按「每莫尔原胞整数个载流子」跳变
**Flat-band-induced integer doping and phase transition in monolayer graphene**
*Nature (2026)*

范德华异质结靠**范德华能、弹性能与库仑能的微妙平衡**维持，界面没有共价键，晶体可以滑移、旋转、重构，因而存在多个竞争的**结构相**；但此前没人做到对这种平衡的可控调节、进而动态控制堆叠。作者做出一个**动力学异质结**：单层石墨烯**两侧分别与块体 hBN 和单层 hBN 双重对齐**。STM 观察到**晶体对称性改变**，即一次**全局结构相变**，可由**栅压、磁场或温度**诱发。伴随的电子相变很奇特：石墨烯的掺杂在**离散能级之间切换**，对应每个**莫尔原胞恰好整数个电子或空穴**。作者把它归因于**莫尔重构（单层 hBN 大幅增强）产生的应变诱导赝朗道能级**（倒空间中的平带）里的电荷俘获。这条「电控结构—电子耦合相变」的路径，为工程化**应变平带与应变—库仑关联**提供了旋钮。

📎 DOI: [10.1038/s41586-026-11254-4](https://doi.org/10.1038/s41586-026-11254-4)

### 💫 仙女座星系 AT 2025abao：首次直接看到 0.7 M☉ 伴星在 7 M☉ AGB 星共包层内旋进，七年渐亮后并合抛壳
**An inspiral of a star inside a common envelope with its giant companion**
*Nature (2026)*

紧凑双星的形成要求前身双星**轨道快速收缩**，理论机制是**共包层演化（CEE）**：两星在松散束缚的共享对流包层中互相绕转，摩擦拖曳驱动旋进。但**这种旋进从未被直接观测到**。作者报告仙女座星系中的暂现源 **AT 2025abao**：爆发前长达数年的光谱最符合一颗约 **0.7 M☉ 的伴星**在约 **7 M☉ 渐近巨星支（AGB）星的对流包层内旋进**，摩擦耗散供能造成约**七年的逐渐增亮**——这是 CEE 摩擦拖曳能量耗散的首批直接观测之一，且该阶段**辐射效率高**，与对流输运的预测一致。随后伴星与主星核心并合，驱动**最外层 10% 包层**以约 **10 倍主星逃逸速度**被抛出，并经验约束「耗散轨道能中可用于束缚/抛射包层的比例」**0.01 ≲ α ≲ 0.4**。

📎 DOI: [10.1038/s41586-026-11221-z](https://doi.org/10.1038/s41586-026-11221-z)

### 🦠 免疫健全的人肠组织工程模型：多谱系上皮 + 黏液层 + 可接触菌群 + 自体免疫细胞，单细胞拆开沙门氏菌「腔内」与「胞内」两套调控网络
**Host–microbe interactions in engineered immunocompetent human gut tissues**
*Nature (2026)*

肠道黏膜是病原体入侵的主要门户，但要研究**人特异性的屏障反应**，模型必须同时具备**结构复杂度**与**自体免疫区室**，此前一直缺。作者构建了**人小肠与结肠的工程化屏障模型**：多谱系上皮、黏液层、可接触的微生物区室，以及**自体组织驻留免疫细胞**；组织在形态与功能上表现出**区域特异性**，可与天然器官相比。用该模型在单细胞水平刻画**鼠伤寒沙门氏菌**感染，作者区分出「**细菌位于肠腔**」与「**细菌已侵入胞内**」背后**不同的基因调控网络**：被入侵的上皮细胞启动 **IL-18 信号轴**，触发**细胞毒性 T 细胞活化**，最终导致**上皮脱落与屏障破坏**。上皮、微生物、免疫三个区室可模块化组合，使其成为研究人肠生理与病理的通用系统。

📎 DOI: [10.1038/s41586-026-11292-y](https://doi.org/10.1038/s41586-026-11292-y)

### 🌴 广西姊妹洞 9 颗牙齿把中国南方直立人推晚到 324–184 ka：他们长期生活在「只属于智人」的封闭雨林
**Rainforest adaptation in late Homo erectus from southern China**
*Nature (2026)*

直立人是**存续最久的人族物种之一**，约 190 万年前到 10.8 万年前分布在非洲到东亚；但它的**适应能力**与在中国**存续到多晚**一直有缺口。过去对直立人生态偏好的假设，多来自爪哇 Trinil、Sangiran、Ngandong 的**开阔林地—草原镶嵌**景观，亚洲的直接稳定碳同位素测量又很少。作者报告中国广西**两个姊妹洞**出土的 **9 颗人族牙齿**（其中 8 颗经形态与遗传鉴定为直立人），并用**五种测年技术的 43 个放射性年龄**建模，建立该区域直立人存续的时间线；再用牙齿的**稳定同位素、团簇同位素与微量元素**重建主导环境与行为响应。结果显示：直立人在中国南方存续于 **324–184 ka**，比此前该区域**约 400 ka** 的确凿记录**晚得多**；证据指向他们**持续生活在封闭雨林生态系统**中——这原本被认为只是**智人的领域**——并表现出**长期移动能力与生态灵活性**。这直接挑战了关于直立人生态偏好与行为局限的既有假设。

📎 DOI: [10.1038/s41586-026-11155-6](https://doi.org/10.1038/s41586-026-11155-6)

### 🧪 把「主动特征获取」变成显式 oracle 蒸馏：不到四分之一采集成本，拿回 90% 可达精度增益
**Active Feature Acquisition by Distilling an Oracle Teacher**
*arXiv (2026)*

逐实例采集全部特征往往代价高昂：一次测量可能带**金钱成本、时间延迟或隐私代价**。**主动特征获取（AFA）**要让策略在预算内决定「这个样本该测哪些特征」。现有方法训练策略时优化的是**自构的效用目标**，而不是从显式教师那里蒸馏。作者把教师**显式构造出来**：训练时标签与未观测特征值都可见，二者**闭式决定**一个 oracle——它按「对下游预测器误差的影响」给每个候选特征排序。**OracleImitator** 用**软目标模仿**把这个排序蒸馏成可部署策略。在多模态医学诊断与 **AFABench** 上，它在整个预算区间追平或超过现有 AFA 方法：**以不到四分之一的采集成本恢复 90% 的可达精度增益**。由于教师是**显式算法对象**而非隐式优化目标，还能直接测量「部署时可见的信息能恢复多少排序」，把可学习性的上限变成可度量的量。

📎 arXiv: [2611.26598](https://arxiv.org/abs/2611.26598)

### 🤖 PGX：把长时程人形 loco-manipulation 的时间结构与精度控制外包给两个免训练经典部件
**PGX: Physically Grounded Execution for Long-Horizon Humanoid Loco-Manipulation**
*arXiv (2026)*

视觉—语言—动作（VLA）模型能执行多样的单项操作技能，但在**长时程 loco-manipulation**（边走边操作）上仍吃力：**时序结构、技能切换与精度被绑在一个单体模型里**。**PGX（Physically Grounded Execution）** 把时间与精度控制**卸载给两个无需训练的经典部件**，让 VLA 只专注**阶段内的技能动力学**。它分三层：**(i) 基于谓词的状态机**管任务推进——用物理谓词**门控相位切换、触发恢复、协调导航与等待**，且共享的谓词语义同时连接**离线演示分段、在线执行与分阶段评估**；**(ii) VLA 技能**只在主动操作相位内工作，平铺或分阶段训练的模型因此专注任务相关动作；**(iii) 世界坐标锁定（WCL）**靠**基座站位保持、物体相对定位、世界锚定接触目标**维持空间一致性。在三个仿真任务与一个 **Unitree G1 人形机器人**真机任务上，阶段推进与任务成功率均有提升。

📎 arXiv: [2611.26596](https://arxiv.org/abs/2611.26596)

### 🧠 用多模态 Jacobian lens 探 VLM 的「全局工作空间」：概念在中间态可读、按任务选择性可及，而且被访问的概念真的参与下游计算
**Probing the "Conscious" Mind: Selective Access and Global Workspace in Vision-Language Models**
*arXiv (2026)*

视觉—语言模型（VLM）能整合图文信息，但**输出并不暴露内部的概念表征**。**全局工作空间理论（GWT）**主张：信息从并行脑过程中被**选择**、在共享工作空间**整合**、再对专门化过程**可用**。作者提出 **Multimodal Concept Lens（MC-Lens）**——一种**多模态 Jacobian lens**：视觉编码器 lens 与语言解码器 lens 把中间状态映射到**由解码器输出词表定义的共享语义空间**，从而跨模态比较概念可及性，并支持**内部概念干预**。工作分四点：**(i) 可及性与选择性访问**——多模态概念信息在中间状态**可读**，并随任务需要**被选择性访问**；作者把 readout carrier 从单个名称 token 扩展为 **token 集**，以更好表达概念并支撑反事实实验。**(ii) 概念参与下游计算**——反事实实验显示被访问的概念信息**确实参与下游计算与推理**。**(iii) 对齐与选择性的发展**——两个 **J-space 指标**在受控 VLM 训练中比隐状态余弦更清楚地追踪**跨模态概念对齐**的发展；且**可靠的选择性访问比概念可读性出现得更晚**。**(iv) 跨模型共享的功能模式**——不同 VLM 家族与规模虽内部组织不同，却表现出**共享的概念可及性、查询依赖的选择性与跨任务干预效应**模式。

📎 arXiv: [2611.26590](https://arxiv.org/abs/2611.26590)

### 🎨 ProtoDiffusion：一张共享空间原型 + 每层一个候选向量，N 层设计的表示只要 HW+N 个 token
**ProtoDiffusion: Token-per-Layer Generative Modeling of Multi-Layer Images**
*arXiv (2026)*

图形设计是 **RGBA 图层的有序组合**，分层带来可选择、可移动、可复用的能力。现有分层模型给**每层**一个**全画布或区域大小的空间潜网格**，表示量随各层累积空间范围增长。作者提出 **ProtoDiffusion**，建在 **ProtoVAE** 上：把一张设计编码成**一张共享的空间原型** + **每层一个候选向量**，每个候选向量条件化**共享解码器**重建对应 RGBA 层。于是 N 层的表示在 backbone 打包前只含 **HW+N 个 token**，而「每层全网格」方案是 **N·HW**。ProtoDiffusion **联合去噪**原型与**固定数量的候选槽**，以图像或文本为条件，**bounding box 作可选布局引导**；不需要的槽可以留空，层数（以及无框时的布局）由模型自己决定，**同一架构同时支持 image-to-design 与 text-to-design**。ProtoVAE 从紧凑共享潜表示重建，层裁剪上达 **40.43 dB PSNR**；LayerD 评测划分上 image-to-design 的 **RGB L1 为 0.040（有框）/ 0.057（无框）**，框引导的 **alpha soft IoU 0.850**，与最强微调基线（0.871）相当；合并图像上的 text-to-design 同样可行。

📎 arXiv: [2611.26586](https://arxiv.org/abs/2611.26586)

### 🕵️ Origin：用跨层依赖图把 agent 轨迹日志与应用代码接起来，5 个 agent 应用、8 起攻击事件全部定位到妥协入口
**Backtracking Agent Applications Security Incidents**
*arXiv (2026)*

agent 应用部署越来越广，**agent 特有的攻击**已成真实威胁。安全事件发生后，组织要**回溯定位 CEP（compromise entry point，妥协入口）**、修复损害并防止复发。可用的主要证据是**轨迹日志**（记录 agent 功能）与**源代码**，而应用级函数调用日志往往很少。难点是一座**语义鸿沟**：轨迹日志处在 **agent 功能抽象层**，CEP 候选却是**应用代码执行层的函数调用**，分析师只能针对每个候选**人工翻代码**去推断对应功能。**Origin** 让分析师只提交**少量查询**就能找出既有工具给不出的 CEP，并解决两个子问题：**(1)** 定义**中间抽象**以刻画两个语义层之间的映射；**(2)** 确定 **region→variable 映射**（region 是一组特定的 agent 功能）以构建该抽象下的图。做法是：**跨层依赖图（CLDG）**把语义层由 region 推断出的函数，连接到低层**污点传播子图**中的变量，并配一套查询语言；再加上 **region 推断算法**。在 **5 个流行 agent 应用、8 起攻击事件**的案例研究中，使用 Origin 的分析师**正确定位了全部 CEP**。

📎 arXiv: [2611.26525](https://arxiv.org/abs/2611.26525)
