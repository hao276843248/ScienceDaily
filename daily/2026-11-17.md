## 🔬 科学前沿

### 🦠 痘病毒核心上开着一个「门」：冷冻电镜解出 4.4 Å 的孔道，一段保守赖氨酸构成窄正电收缩口
**Architecture of a portal complex embedded in the poxvirus core**
*Nature (2026)*

痘病毒有个古怪之处：它的基因组复制发生在宿主细胞质里，但**早期转录是在病毒核心（core）内部完成的**——核心进入胞质后与侧体解离、膨胀，成为一个转录隔室。问题随之而来：**分子怎么在核心内部与宿主胞质之间进出**？作者用**冷冻电子断层扫描 + 子断层平均**，在牛痘病毒（vaccinia）核心上解出 **portal complex 6.7 Å、中央孔 4.4 Å** 的结构。结合结构预测与实验密度，认定 **E8、E6、L3** 三个病毒蛋白是孔的主要组分并给出排布模型。孔内有一个由 **L3 中保守赖氨酸**构成的**窄、带正电的收缩区（constriction）**，把这些赖氨酸替换掉会**削弱病毒基因表达与增殖**；通道的尺寸与静电性质与「跨核心壁的分子交换」相符。要点是：**这个「转运口」不是猜出来的通道，而是有结构、有突变表型、有电荷属性的实体**——痘病毒（含天花、猴痘）的转录隔室第一次有了可下手的结构界面。

📎 DOI: [10.1038/s41586-026-11399-2](https://doi.org/10.1038/s41586-026-11399-2)

### 🧬 人类复制体自带一个「专用前导链引物酶」：CMG 直接抓住 PRIMPOL，缺口最小，断开就不重启
**Human replisomes direct a dedicated leading-strand primase for fork restart**
*Nature (2026)*

前导链合成受阻会拖慢甚至卡死复制叉——因为 **Pol ε 的合成是 CMG 解旋酶高效解链所必需**。重启的办法之一是在障碍物下游**重新起引物（repriming）**，人细胞里靠 **PRIMPOL**（兼具引物酶与聚合酶活性），但它**如何被复制体调度**一直不清楚。作者用**纯化人蛋白重构停叉与重启**，得到三点：**CMG 直接结合 PRIMPOL 并把它定向到前导链**起引物；**冷冻电镜结构**显示这种定向使**复制后缺口（post-replicative gap）降到最小**；**意外的是 PRIMPOL 与 RPA 的相互作用在此体系中并非重启所必需**（与长期假设相反）。破坏 CMG–PRIMPOL 相互作用后，**体外重启消失**，人细胞中 **PRIMPOL 依赖的 DNA 损伤耐受也消失**。意义在于把 PRIMPOL 从「应急替补」改判为**复制体的组成部分**：谁起引物、起在哪条链，是**由解旋酶亲自指定的**，不是随机补位。

📎 DOI: [10.1038/s41586-026-11204-0](https://doi.org/10.1038/s41586-026-11204-0)

### 🎯 把 AR 与 p300/CBP「焊」在错误构象上：DALTAC 让前列腺癌的新生增强体整体崩塌，比双抑制更强
**Domain-alteration chimeras rewire oncogenic complexes in prostate cancer**
*Nature (2026)*

转移性去势抵抗前列腺癌依赖**雄激素受体（AR）**，而 AR 是通过**域特异的相互作用**去招募乙酰转移酶 **p300/CBP** 来维持致癌转录程序的。作者提出一种新的治疗模态——**domain-alteration chimera（DALTAC）**：不去抑制任一蛋白的活性位点，而是**强制非天然的域—域靠近**。首个分子 **DALTAC-1** 把 **AR 的配体结合域**拉近 **p300/CBP 的溴域**，错配原生界面、把复合物锁进**非生产状态**，产生「**超抑制（super-inhibitory）**」效应——**压制 AR 驱动的转录与增殖比同时抑制 AR 和 p300/CBP 更彻底**。机制上是**重编程 p300/CBP 的底物选择**：**取消 H2B N 端乙酰化**、反过来诱导 **AR 与共激活因子的新形态（neomorphic）乙酰化**，最终让 **AR neo-enhanceosome 崩塌**；染色质层面 AR/p300/CBP **重新分布到回文 ARE**，致癌 **AR/ERG neo-enhancer 上的辅因子与转录机器招募被破坏**。谱系选择性很高——**AR 双依赖细胞敏感、AR 阴性细胞不受影响**，多个体内模型出现**深度且持久的肿瘤消退**。可迁移的一点：**「把两个蛋白绑错」比「把某个蛋白关小」更难被细胞补偿**。

📎 DOI: [10.1038/s41586-026-11262-4](https://doi.org/10.1038/s41586-026-11262-4)

### ⚡ 磷介导的「反向氢溢流」：让硝酸盐还原与硫酸盐氧化速率对齐，一边产氨一边产过硫酸铵
**Phosphorus-mediated reverse hydrogen spillover enables rate-matched nitrate-sulfate paired electrolysis for ammonium persulfate synthesis**
*Nature Communications (2026)*

把硝酸盐废水变成铵是好事，但**硝酸盐还原动力学慢**、与阳极氧化**速率不匹配**，配对电解因此很难真正跑起来。作者在 **PdP₂@Cu₃P 异质界面**上做「**反向氢溢流**」：活性氢从产氢位点被**搬到硝酸盐活化位点**，实现 **P 介导的快速加氢**，从而把「产氢」与「耗氢」**在时间上解耦**，并**绕开多步质子耦合电子转移（PCET）**。原位光谱 + 从头算分子动力学支持该机制。读数：硝酸盐还原速率 **8.94 × 10⁻⁷ mol cm⁻² s⁻¹**、产氨法拉第效率 **>92%**、**220 mA cm⁻² 稳定运行**；膜电极配对电解槽产 **过硫酸铵 1.6 mmol h⁻¹ cm⁻²**，**能耗比传统路线低 55%、CO₂ 排放低约 99.6%**。这意味着「污水处理 + 产氨 + 产氧化剂」可以是同一次电解，而关键不是加电位，是**把中间体在空间上挪对位置**。

📎 DOI: [10.1038/s41467-026-79620-4](https://doi.org/10.1038/s41467-026-79620-4)

### 🪲 甲虫的「逆流交换器」怎么长出来：一个差异剪接的 FGF 受体 + 两条配体，协调四套组织拼装
**Assembly of a renal countercurrent system in a beetle**
*Nature Communications (2026)*

**隐肾复合体（cryptonephridial complex, CNC）**是昆虫的水分守恒装置：把**马氏管与后肠**排成**逆流构型**、再用一层来源不明的 **perinephric membrane** 封成腔室，效率远超顺流，甚至能用来从空气里取水。它由「内部解剖的剧烈重组」演化而来，但**发育上如何拼装**一直空白。作者在模式甲虫**赤拟谷盗（Tribolium castaneum）**里追踪 CNC 发育，发现**后肠、马氏管、perinephric membrane、气管**四类前体细胞之间的**动态 crosstalk** 只依赖**一个差异剪接的 FGF 受体与两条 FGF 通路配体**；并把这层膜的来源锁定为**一群此前未被描述的中胚层细胞**。要点：**一套高度复杂的多器官逆流系统，其「总开关」是一个受体的剪接异构体**——发育用「同一个信号、不同接收器」来分派四种组织的装配任务，这为它的演化起源提供了线索。

📎 DOI: [10.1038/s41467-026-79593-4](https://doi.org/10.1038/s41467-026-79593-4)

## 🤖 AI前沿

### 🧪 WeightBench：42 个任务测「直接读写权重」，前沿模型能写小网络，却不会给语言模型打补丁
**WeightBench: Evaluating Language Models as Weight-Space Programmers**
*arXiv (2026)*

已有工作显示 LLM 可以直接操作别的网络的**参数**：读出它被训练成做什么、修好坏掉的网络、从零写出能跑的网络，且**不用梯度下降**——这被称为**权重空间编程（WSP）**。**WeightBench** 把它拆成 **42 个任务、五个 track**：读权重、修权重、写权重、**识别不可能的编辑**、**无数据压缩**；被测网络从 **2K 参数的控制策略到 7B 语言模型**。读数：42 任务宏平均 **Claude Opus 5.5 0.535**（Sonnet 5.5 0.466、Haiku 5.5 0.402、DeepSeek v4-flash 0.215），在它跑过的 38 个任务上 **GPT-6.1-sol 0.568 vs Opus 0.546**。结论很清楚：前沿 agent **已能读小网络、且不用实际运行就写出可工作的控制策略**；但**不能给语言模型打补丁、不能无数据压缩、也分不清「做不到」与「很难」**。后者是更根本的短板——它意味着模型对自己的操作能力**缺少标定**。

📎 arXiv: [2611.18553](https://arxiv.org/abs/2611.18553)

### 🔍 验证判断能穿过抽象层吗：31% 的判定在宏抽象/委派下失效，恢复出处能救回 85.5%
**Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation**
*arXiv (2026)*

LLM verifier 被大量用来评 agent 的执行，但它们的可靠性几乎总是在**单一轨迹表示**下测的；真实系统里同一次执行可能被**组合工具、委派边界、压缩历史**重新暴露给 verifier，**能看到的证据变了**。作者提出 **Verification Transport**：对同一批**冻结的执行**构造 native / abstracted / restored 三种视图，**固定**任务、真实轨迹、结果、真值、判据与 verifier。覆盖 **4 个 agent 评测基准 × 7 个 verifier 骨干 × 4 种验证协议 × 3 类抽象边界**，发现**运输失败最高约 31%**（宏抽象与委派下）。协议间差异明显：**直接验证更容易给出错误判决**，而**证据落地式与审议式协议在低可观测下倾向弃权**——所以「失败率低」**不等于**更可靠，可能只是更爱说不知道。**恢复执行出处能挽回 85.5% 的失败**，出处有损或缺失时恢复率下降。含义：**native 视图下的准确率不足以刻画 verifier 的可靠性**，凡跨抽象边界做评测，必须报告运输失败率。

📎 arXiv: [2611.18471](https://arxiv.org/abs/2611.18471)

### 🧠 用机制可解释性解释 agent 失败：0.80 AUC 预测「点了不存在的按钮」，但换个动作格式就失效
**Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination**
*arXiv (2026)*

机制可解释性（MI）在解释 LLM 内部计算上进展很大，但在解释 **agent 的决策失败**上还没兑现。作者挑了一个具体失败：**web agent 幻觉出网页上不存在的动作**，在 **Qwen2.5-7B-Instruct** 与真实网站交互时做系统机制分析。结果一半是好消息：**最后一个 prompt token 上的线性探针**能在生成前以 **0.80 AUC** 预测幻觉；**沿探针方向做 steering 能纠正 85% 的幻觉**，代价是**破坏 7% 的有效动作**。另一半是警告：探针方向**对 prompt 格式敏感**——动作表示稍作改动，steering 效果就大幅流失；**回路识别困难**，因为计算分散在多个组件与位置，且 agent 依赖的信息**逐例变化**。结论对方法论有意义：**标准 MI 的假设（单一方向、可定位回路、稳定特征）在真实 agent 失败上并不成立**，「能在某格式下纠正」距离「能解释为什么失败」还很远。

📎 arXiv: [2611.18514](https://arxiv.org/abs/2611.18514)

### ⏱️ VelServe：用自己迭代延迟的尾部来校准每步能塞多少 prefill，SLO 有效吞吐提升 2.4–2.9×
**VelServe: Taming Decode Jitters in LLM Inference with Tail-Calibrated Scheduling**
*arXiv (2026)*

**decode jitter** 很贵：一次抖动会拖慢 batch 里**每一个**请求，而长回答跨数百步，所以**罕见的超时也会累积成大量 SLO 违约**。聚合式服务里，SLO-aware 调度把每步的 prefill 预算**顶到刚好满足 TBT 目标**，于是没给误判与主机停顿留任何余量；分离式部署能达平均 TBT，但**接纳新请求的那些步仍然跑晚**。**VelServe** 的做法是：用**实测迭代延迟的尾部分布**校准每个 decode step 能承载多少 prefill（SLO 决定「多罕见才算越界」），从而在每步留出 headroom；headroom 会拖慢 prefill，于是**最短等待的 prompt 优先**（当 TTFT 期限随长度增长时，被推迟的长 prompt 恰好余量最多）；分离部署下按 **P99 目标**限制接纳节奏。读数：三种 attention 家族、多种负载下，**Qwen3-8B 与 DeepSeek-V4-Flash 上 SLO goodput 是最强基线的 2.4–2.9×**，**DeepSeek-V2-Lite 上 ≥4.4×**；8 GPU 分离部署时满足 SLO 的请求数是 SOTA 的**两倍以上**。

📎 arXiv: [2611.18392](https://arxiv.org/abs/2611.18392)

### 📈 TradeGauntlet：可重放的限价单簿测交易 agent 合规，观测到的「行为警报」全是自成交，闸门压掉约 15% 双边成交
**TradeGauntlet: Evaluating Compliance Controls for Autonomous Trading Agents**
*arXiv (2026)*

自主交易 agent 需要**既能拦住问题订单、又不把正常任务搞到不可用**的控制。**TradeGauntlet** 是一个**可重放的限价单簿模拟器**，把**检测、阻止、执行成本**三者分开测。在 **1,680 个模拟 session**（Claude Haiku 5.5 / Sonnet 5.5）里，作者发现**观测到的所有 conduct alert 其实都是自成交（self-match）**：**拒绝自成交订单的闸门直接清零这些警报**，但**聚合闸门让 Sonnet 的双边成交减少约 15%**。行为提醒降低了 Sonnet 的警报率，却**降低 Haiku 的成交且没有可检测的警报收益**——即**「零警报」完全不等于「合规」**。更狠的一步是用**脚本化探针 + 两种搜索**去找规则之外的空子：搜索找到能**绕过现行规则拆单排程**；学习基线能抓住全部 **2,400 个搜索出的 episode**，但同时会把一个大做市商 **15% 的 session 标红**。对抗性 prompt 让 Sonnet 在 **240 轮里全部拒绝**，反而**没有可评估的策略**。结论对「合规基准」是通用的：**要有能被攻破的对手、要看误伤、要承认结论依赖市场假设**（作者明说本文不证明法律合规或真实市场检测精度）。

📎 arXiv: [2611.18493](https://arxiv.org/abs/2611.18493)
