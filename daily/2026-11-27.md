## 🔬 科学前沿

### 🦷 广西两洞 4 颗牙齿：一个「丹尼索瓦亲和」群体，加一支鉴定不出的古老型人类
**Middle–Late Pleistocene Denisovans and unresolved Homo in southern China**
*Nature (2026)*

东亚中晚更新世的古老型人类近年多被归入丹尼索瓦人，但**同时期是否还有别的支系**一直不清楚。作者在广西**传山洞（Chuanshandong）与龙船洞（Longchuandong）**两个洞穴遗址报告 4 颗游离牙齿，年代分别早于 **100.8 ka** 与 **104.5–42.6 ka**，把牙形态学与**古蛋白质组**（牙釉蛋白 AMELY/AMBN 的单氨基酸多态性）合起来做鉴定，结果是**至少两个谱系**。龙船洞标本的牙形态与**阿尔泰丹尼索瓦人高度相似**，且氨基酸变异与**哈尔滨、澎湖、蝙蝠洞、阿尔泰**丹尼索瓦人一致 → 判为**丹尼索瓦亲和群体**；传山洞标本携带与**先驱人及大猿共享**的祖先型 **AMELY 179M**、以及**东亚中更新世直立人诊断型 AMBN 253G**，却**缺**丹尼索瓦相关的 **AMBN 273V**，形态上祖征与衍征镶嵌、无明确丹尼索瓦亲和 → 只能记为**未定的古老型人类（unresolved archaic Homo）**。这意味着亚热带中国在中晚更新世可能同时容纳**多种人族群体**，而不只是一支连续演化的丹尼索瓦人。

📎 DOI: [10.1038/s41586-026-11341-6](https://doi.org/10.1038/s41586-026-11341-6)

### 🌾 借一个极端微生物的转录因子：小麦小区产量 +19.4–32.8%，水稻玉米单株 +19.7–42.4%
**An extremophile transgene improves drought resistance and yield in cereals**
*Nature (2026)*

抗旱与高产通常此消彼长——中度干旱年平均就让作物减产 30–40%，而抗逆通路一旦常开就要付出生长的代价。作者把一个**地衣共生真菌（极端微生物）在渗透胁迫下诱导的转录因子基因 *EpTFIIAγ*** 异源表达到谷物里：该蛋白**与作物内源的转录激活因子物理互作**，协同增强**胁迫响应与发育两套转录程序**，从而同时提高**光合能力与水分利用效率**、并**延缓衰老**。田间与水分亏缺（water deficit）条件下**五个小麦品种小区产量提高 19.4–32.8%**，水稻与玉米的**单株产量在温室与多个田间环境中提高 19.7–42.4%**。作者称其**部分解耦了抗逆与产量之间拮抗的通路**，是一条不依赖水分条件、广谱适用于主粮的增产路线。

📎 DOI: [10.1038/s41586-026-11151-w](https://doi.org/10.1038/s41586-026-11151-w)

### ⚡ 6 nm 宽的 NbP 纳米带电阻率 18 μΩ·cm：越窄反而越低，和铜相反
**Unconventional resistivity reduction in NbP semimetal nanoribbons**
*Nature (2026)*

金属互连缩到纳米尺度后电阻率会因**表面与晶界散射**急剧上升，这是后摩尔时代互连的关键瓶颈。作者用**工业友好的自上而下工艺**把**拓扑半金属磷化铌（NbP）**做成窄至约 **6 nm** 的纳米带，在约 **9 nm² 截面**下测得室温电阻率 **18 ± 4.1 μΩ·cm**，**低于同尺寸的常规金属与半金属**。更反直觉的是**电阻率随宽度减小而下降**——与铜等金属的经典行为相反，说明随截面收缩，**表面态与边缘态的输运贡献相对上升**，即使存在边缘粗糙等无序。这为纳米尺度导线与互连提供了一个可继续缩放的平台，也把「半金属表面态能不能当导电通道用」从猜想变成可测的尺度律。

📎 DOI: [10.1038/s41586-026-11288-8](https://doi.org/10.1038/s41586-026-11288-8)

### 🧬 酶促「活性聚合」合成多糖：分子量 660 kg/mol，分散度 <1.05
**Enzymatic living polymerization for polysaccharide synthesis**
*Nature (2026)*

多糖在生物过程里功能极多，但合成**结构明确**的类似物一直很难——传统化学法靠保护基操作，**高分子量、立体化学控制、序列精度**三者难以兼得。作者提出**酶促活性聚合**：关键在于**引发剂与聚合酶结合较弱**，使**活性（结合）与休眠（未结合）物种之间快速平衡**，从而表现出活性聚合特征（机理与计算研究共同支持）。结果得到分子量高达 **660 kg mol⁻¹**、**分散度最低小于 1.05** 的天然多糖，并可推广到**序列受控的嵌段共聚物**等多样多糖类型。这条路避开了保护基，为研究多糖**分子量依赖的生物学功能**提供了模块化平台。

📎 DOI: [10.1038/s41586-026-11304-x](https://doi.org/10.1038/s41586-026-11304-x)

### 🍬 果蝇的肠—脑感觉运动回路：肠道测到糖，就让嗉囊「放开闸门」
**A gut–brain sensory-motor circuit regulates sugar ingestion in *Drosophila***
*Nature (2026)*

肠与脑的双向通讯决定取食偏好与进食量，但**肠道营养传感如何直接接到进食运动控制**上一直缺具体回路。作者在果蝇里找出一条**肠—脑感觉运动回路**：**穿透前肠上皮的肠感觉神经元**在进食过程中检测肠腔内的糖，把兴奋性输入送给调控取食的脑神经元 **IN1**；功能成像与**连接组分析**显示 IN1 整合多路糖感觉输入（含肠感觉神经元），并对**控制嗉囊入口肌肉的肠运动神经元**发出**抑制性**输出。进食时 IN1 被激活 → 抑制这些肠运动神经元 → **嗉囊导管舒张** → 食物被**快速送入嗉囊**，从而维持持续取食。这把「吃多少」的调节从激素/代谢层面落到了**一条可指认的感觉—运动接线**上，也提示肠道信号是在**运动执行的当口**动态改写进食节奏。

📎 DOI: [10.1038/s41586-026-11315-8](https://doi.org/10.1038/s41586-026-11315-8)

## 🤖 AI前沿

### 🤖 编码 agent 到底「多改」了多少？逐块回滚 + 重跑测试，把多余编辑归因到具体步骤
**How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches**
*arXiv (2026)*

agent 的补丁比开发者的大，通常被直接读成「过度编辑」，但**补丁大小说不清多出来的改动是否必要、是什么、从哪来**。作者提出 **Delta Residue Attribution（DRA）**：重放 agent 轨迹，把最终补丁的每个单元**追溯到写下它的那一步**，逐个回滚并**重跑任务测试**来判定是否必要。在 **18 个前沿模型、7,660 条已解决的 GitHub Copilot CLI 轨迹**（SWE-bench Verified 6,728 + DeepSWE 932）上运行，并对开发者补丁用同一方法打分。结果：agent 确实改动更多行，但 SWE-bench Verified 上多余的改动主要是**加测试（61%）与文档（13%）**，DeepSWE 上则多为**代码（58%）**；两个基准上 agent 的代码**平均至少和开发者一样必要**（必要比例 **0.887 vs 0.864**，18 个模型中 **11 个**留下的无用代码比开发者更少；DeepSWE **0.797 vs 0.785**）。平均仍有 **11%** 的代码单元不必要，其中 **89% 会改变行为**；用 agent 可见的测试做 DRA 剪枝能去掉多数无用代码（召回 67%、精度 46%），**89%** 剪枝后补丁仍能解任务。作者因此建议基准**在解决率旁边报告「代码必要性」**，并把过度编辑交给训练与 harness 层解决。

📎 arXiv: [2611.34875](https://arxiv.org/abs/2611.34875)

### 🎓 REE：给 AI agent 的「科研入学考试」——100 道开放题、12 小时迭代，Opus 5.5 与 GPT-6.1 Sol 在 86%/81% 的题上超过专家解
**REE: A Scientific Research Entrance Exam for AI Agents**
*arXiv (2026)*

评估自主科研 agent 需要能提出**开放式研究问题**并衡量「相对既有科学方法改进了多少」的基准。**REE** 由 **100 道开放研究题**构成，覆盖**五个大学科、23 个领域**，每题都取自该领域**正在进行的研究**并经领域专家逐题评审。任务形式是**迭代改进**：agent 最多有 **12 小时**改进一个可运行的起始解，REE 在**统一尺度**上把结果与「同等条件下评估的专家解」比较。四个前沿 agent 中，**Claude Opus 5.5 与 GPT-6.1 Sol 分别在 86% 与 81% 的题上超过专家解**，且覆盖全部五个学科；过程记录显示两者**平均在两小时内**就超过专家解，最佳解**多为对领域既有方法的裁剪与组合**而非新原理。这说明该基准同时抓住了「改进幅度」与「改进方式」，也让「agent 会不会做科研」这个问题第一次有了可比的分数线。

📎 arXiv: [2611.34646](https://arxiv.org/abs/2611.34646)

### 🖼️ VisualMontage：用真实图片 + 局部忠实的图注，把 VLM agent 的结论「策展」到攻击者想要的方向
**VisualMontage: Manipulating the Beliefs of Vision-Language Agents with Authentic Image Sequences**
*arXiv (2026)*

VLM agent 越来越多地解读社交媒体内容，于是出现一种新威胁——**视觉认知合谋**：多条协同帖子用**真实图片 + 局部忠实的图注**，让 agent **靠自己的推理**得出并接受攻击者选定的结论（单条帖子都不违规）。作者构建**544 个目标案例、33.2K 张候选图、8 个应用领域**的基准，并提出多 agent 框架 **VisualMontage**：叙事规划 → 图像选择与排序 → 图注分配 → 迭代评审。在 **12 个 VLM** 上用**同一套攻击流、不做受害者专属优化**，仍得到**跨模型可迁移**的攻击成功率：闭源 **61.93%**、开放权重 **68.71%**，且 **92.65%** 生成的 feed 通过独立的模型化有效性审计。即便经过下游审查，**残余成功率仍有 35.3%–76.7%**；对照实验还发现图注能提升帖子「自然度」评分却**降低**攻击成功率。威胁的重点不在单图真伪，而在**多张真图组合起来讲的这个故事**。

📎 arXiv: [2611.34603](https://arxiv.org/abs/2611.34603)

### 🧠 TASK Memory：记忆不是「取不到」，而是「取到了不用」——文本给内容，知识编辑给地址，一对 steering 向量决定用不用
**TASK Memory: Beyond Text-Only Memory with Activation Steering and Knowledge Editing against Memory Hallucination**
*arXiv (2026)*

agent 的外置记忆检索到了、放进了 prompt，回答却**与记忆矛盾**或**把记忆套到错的实体上**——作者称之为**使用期记忆幻觉**，并在五个开源模型上归为三类：**忽略记忆**（退回到权重里的旧事实，最高 **46%** 查询）、**误用记忆**（安到无关实体，最高 **24%**，检索叠加权重编辑时达 **49%**）、**版本混淆**（新旧两版都在库里时，**53%** 的回答断言已被取代的旧值）。**TASK memory** 把「文本笔记 + activation steering + 知识编辑」三者**共享同一个模型内地址**：文本存内容；**可移除的知识编辑**用 subject key 提供地址并支持多跳组合；**一对 steering 向量**逐个查询决定「采用记忆」还是「保留自己的答案」——向量**不存内容**，只控制文本记忆怎么被使用。在冻结模型、预注册且只测一次的条件下，十个「模型×数据集」格子里**忽略记忆型幻觉降到 ≤1.5%**，邻实体误用从 **39.2% 降到 7.5%**（CounterFact 综合 +10.8 点）；**300 条记忆库上比 BM25 RAG 高 16.4 点**（3,000 条时优势仍在），无需 fact ID 即可处理事实修订，MQuAKE 多跳 **+7.5 点**。**23 个跨模型对比中 21 个显著**（8B–27B、四家族）。

📎 arXiv: [2611.34762](https://arxiv.org/abs/2611.34762)

### 🌍 能读世界模型源码时，还需要 RL 吗？让编码 agent 直接合成控制策略
**Do We Still Need Reinforcement Learning When We Can Read the World Model?**
*arXiv (2026)*

基于模型的 RL 用世界模型支撑**规划或策略优化**，但仍要大量交互经验。作者研究另一条路：让**自主的 LLM 编码 agent 直接在可读的世界模型上推理**，**合成控制策略**。agent 阅读环境源码，把环境知识翻译成**可执行的决策规则**，再用在线反馈或离线数据迭代改进，**不做任务专属的 RL 训练**。在多个决策基准上，合成策略**追平或超过常规 RL 方法**，而所需经验显著更少；进一步分析给出了**可解释的决策规则**及其随反馈演化的过程。与「不给源码」的生成策略以及若干困难条件下的实验对比，共同说明**可读的世界模型**才是收益来源——这把「试错」换成了「读代码 + 推理」，也挑战了「做决策必须靠任务专属 RL」这一默认前提。

📎 arXiv: [2611.34656](https://arxiv.org/abs/2611.34656)
