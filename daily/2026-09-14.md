## 🌍 科学前沿

### ✂️ 碱基编辑修复 PCSK9 与人胚胎发育：效率高但仍不宜临床
**Highly efficient base editing at PCSK9 and normal human embryo development**
*Nature (2026)*

Cas9 诱导的双链断裂在人类胚胎中具遗传毒性，常引发非整倍体与大片段缺失。本文直接评估碱基编辑器在人胚胎 PCSK9 与 HBG 位点引入的缺口/错配的修复结局：以蛋白质形式在受精时递送 ABE8e-V106W，可编辑所有 PCSK9 等位基因，支持发育至囊胚并建立纯合编辑的干细胞系，且未检测到插入缺失，仅偶发靶向染色体断裂与染色体异常。但旁观者与脱靶位点的编辑呈嵌合状态，且以 mRNA 形式引入编辑器会因非向导依赖的脱氨酶活性导致频繁胚胎停滞。结论：碱基编辑器损伤可被高效修复，异于 Cas9 断裂；但基因组与发育的残余风险当前仍排除其在生殖临床中的应用。

📎 DOI: [10.1038/s41586-026-11118-x](https://doi.org/10.1038/s41586-026-11118-x)

### ⏱ 生成式俘获门控路径采样：破解分子转变的时间尺度难题
**Breaking timescales with generative sampling of conformational transitions**
*Nature (2026)*

蛋白折叠、变构与膜转运等分子转变天然稀有，远超标准分子动力学可达尺度，增强采样又昂贵且依赖人为参数。本文提出 Gen-COMPAS，一个生成式匹配者门控路径采样框架：用去噪扩散概率模型生成结构上合理的中间靶点，再经匹配者（committor）过滤识别过渡态，从中间态出发的短时长无偏模拟即可在纳秒至亚微秒聚合尺度上获得过渡区系综——常规方法需要多个数量级更多的采样。在从迷你蛋白到五聚体配体门控离子通道的体系中，仅凭已知端点结构即可恢复匹配者、过渡态与自由能景观，无需预定义反应坐标或先验机理。这是把生成模型引入生物分子机制模拟的一次可计算可行的收敛。

📎 DOI: [10.1038/s41586-026-11025-1](https://doi.org/10.1038/s41586-026-11025-1)

### 🧬 家族内祖先效应：墨西哥人群复杂性状的无偏估计
**Within-family effect of ancestry on complex traits in a Mexican population**
*Nature (2026)*

人群间的类型差异究竟多大程度源于遗传，对多数复杂性状仍是未知数。对遗传混合人群做家族内分析，可得到不受祖先-环境相关混淆的祖先效应估计。作者利用墨西哥城前瞻性研究的数据，评估 52,583 名无亲缘个体与 17,627 个家庭的 39,714 名亲属的遗传祖先与 15 种复杂性状。人群层面，较欧洲祖先，美洲原住民祖先使身高降低 1.98 个标准差、2 型糖尿病对数比值比 1.73；家庭内则分别为 −1.51 与 5.13，且与性状相关位点等位基因计数的祖先间差异及选择信号一致。值得注意的是，教育程度等在人群中显著关联的性状在家庭内并无祖先效应，指向环境成因或混淆。这为\"祖先-环境去混淆\"提供了家庭内因果证据框架。

📎 DOI: [10.1038/s41586-026-11039-9](https://doi.org/10.1038/s41586-026-11039-9)

### 💤 新皮层长程抑制神经元：促进皮质同步与睡眠
**Neocortical long-range inhibition promotes cortical synchrony and sleep**
*Nature (2026)*

睡眠与觉醒对应不同皮层节律模式，低唤醒（如慢波睡眠）时低频节律在大范围皮层同步。本文在小鼠中发现一类稀疏且遗传上独特的 GABA 能神经元——共表达生长抑索（Sst）与软骨凝集素（Chodl）——在低唤醒状态选择性激活、高唤醒时基本沉默。与多数皮层抑制神经元不同，Sst-Chodl 细胞极稀疏却经长程轴突同时支配多个皮层区域，产生广泛影响。选择性激活这些细胞足以促进低唤醒特有的多区皮层同步并诱导睡眠。这证明长程抑制神经元不仅追踪行为状态，更能主动促进睡眠——皮层回路在睡眠调控中具有独立于经典皮层下机制的关键作用。

📎 DOI: [10.1038/s41586-026-10876-y](https://doi.org/10.1038/s41586-026-10876-y)

### 🧩 GPN-Star：以系统发育感知基因组语言模型预测全基因组功能约束
**Predicting genome-wide functional constraints with GPN-Star**
*Nature (2026)*

基因组语言模型可从 DNA 序列学习全基因组功能约束，但标准自然语言式模型常需巨大算力且在预测任务上不及经典进化模型。本文提出 GPN-Star，一个生物学锚定的基因组预训练网络：采用系统发育感知架构，显式利用全基因组比对与物种树建模进化关系，在脊椎动物、哺乳动物与灵长类时间尺度训练。它在人类基因组编码与非编码区的各类变异效应预测任务上达到 SOTA。相比以往方法，GPN-Star 在优先排序致病变异与精细定位 GWAS 变异上显著更优，复杂性状遗传力富集更强，并提升罕见变异关联检验功效；还扩展到鼠、鸡、果蝇、线虫等五个模式物种。这是\"进化信息 + 语言模型\"改进人类遗传学分析的代表性进展。

📎 DOI: [10.1038/s41586-026-11005-5](https://doi.org/10.1038/s41586-026-11005-5)

## 🤖 AI前沿

### 🧫 生物在环：CRISPR 筛选的自适应命中发现，富集 5.67 倍
**Biology-in-the-loop: Amortized Adaptive Hit Discovery in CRISPR Screens**
*arXiv:2609.11877 (2026)*

生物学发现常在有限预算下需顺序选实验，CRISPR 筛选即典型例子。针对自适应命中发现基准稀缺，作者提出 AssayBench-Loop——含 1,389 个跨五类表型的 CRISPR 筛选的大规模基准，其规模足以跨历史实验学习采集策略。基于此提出 AssayLoop：AssayFormer（跨历史筛选训练的 transformer 平摊采集策略，从实验反馈自适应）+ 经自适应移交引入 LLM 生物学先验；并推出 AssayLLM 展示同一原理可经任务后训练直接延展到 LLM。在时间留出的筛选上，AssayLoop 相对随机选择富集 5.67 倍，在检测约 5% 候选库后恢复 27.7% 的命中，优于现有自适应方法与独立 LLM。这是\"把完成实验当训练数据来学下一步测什么\"的生物在环范式落地。

📎 arXiv: [2609.11877](https://arxiv.org/abs/2609.11877)

### ⚖️ 统一的逐 token 门控族：在线蒸馏中 FKL/RKL 混合
**A Unified Per-Token Gating Family for On-Policy Distillation: FKL/RKL Mixing with Multi-Channel and Bias Coefficients**
*arXiv:2609.11768 (2026)*

逐 token 门控前向/反向 KL 损失已成在线知识蒸馏（OPD）的标准技术，但 EOPD、ToDi 等方法各固定单一门控信号与方向，从未被直接比较。本文提出四系数参数化 λ_t = σ(a·h_t + b·u(x) + c + d·gap_t)，将 EOPD 与 ToDi 的方向对齐代理视为其一维限制，并引入多通道组合与显式偏置。在 TweetEval 情感与仇恨任务（Qwen3-32B 教师蒸馏至 Qwen3-4B 学生）上，全族配置在 36 个可比单元中的 33 个超过匹配幅度的单通道一维限制；隔离实验将动态门控置于有效-KL 匹配的静态基线之前。三种子配对复现方向一致但个体未达 n=3 显著。该参数化主要价值在于为短输出分类 OPD 的门控设计提供共享坐标系。

📎 arXiv: [2609.11768](https://arxiv.org/abs/2609.11768)

### ✂️ LOCUS：任务感知低秩后训练，让语言生成更省 token
**LOCUS: Task-Aware Low-Rank Post-Training for Token-Efficient Language Generation**
*arXiv:2609.11739 (2026)*

LLM 服务成本随输出长度直接缩放，而标准偏好对齐常在不提升效用下助长冗余冗长。作者研究后训练更新的参数化是否影响生成长度：低秩子空间可在不修改对齐损失的前提下改变序列长度。LOCUS 选择任务感知的低秩适配子空间，在效用约束下最小化输出 token 成本；在该子空间内后训练保留原生偏好目标与冻结骨干。在 HH-RLHF 对话偏好上（Pythia-2.8B 与 Qwen2.5-3B 两个约 3B 解码器）与全参数 DPO/DrDPO 基线对比：LOCUS 使 Pythia 续写长度最多缩短 39.84%、Qwen 缩短 14.87–17.58%，仅更新 0.24–0.28% 参数，内部偏好诊断无实质变化。这是把\"对齐方向\"与\"长度经济性\"解耦的低秩后训练新视角。

📎 arXiv: [2609.11739](https://arxiv.org/abs/2609.11739)

### 🤝 智能体意见分歧时：以贝叶斯反向推理作无标签锚点
**When Agents Disagree: Bayesian Backward Reasoning as a Label-Free Anchor for Multi-Agent Collective Decision-Making**
*arXiv:2609.11709 (2026)*

当多个 LLM 智能体给出矛盾答案时，聚合方式决定多样性提升性能还是放大共同错误。现有投票、选举规则与 LLM 裁判都依赖前向推理（证据→标签单向映射），聚合的前向估计共享同一分解方式而可能继承相关误差。作者从显式似然经贝叶斯反向推理为每个实例构造反向后验；前向与反向后验提供不同分解的近似的后验，不同分解间共享同一误差的概率更低，故用 Jensen–Shannon 散度按跨路径一致性给智能体排序，衍生硬选择（MinJS）、软重加权（FwdJS）与对数线性融合（LogLin）。在 DDXPlus 上五个 LLM 骨干中一致提升：MinJS 全面优于随机选择、LogLin 最优且在最分歧子集上增益最大。反向后验虽自身准确率较弱，却是有用的互补锚点。

📎 arXiv: [2609.11709](https://arxiv.org/abs/2609.11709)

### 🐍 COBRA-Skills：上下文赌博机引导的智能体技能进化
**COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization**
*arXiv:2609.11682 (2026)*

LLM 智能体可受益于从过往任务经验蒸馏的可复用技能，但现有技能优化常依赖昂贵的执行评估与大量任务数据。COBRA-Skills 把技能优化形式化为对动态演化候选空间的预算受限顺序优化：以上下文赌博机引导的优先级选择 + 证据锚定的技能进化，选择性把评估分配给有前景或有信息量的候选，同时从执行反馈持续精炼技能群。在六个异构智能体基准与三个目标模型上，它一致取得对比方法中最强的平均性能，相对 SkillOpt 降低 55–58% 的优化成本，每个基准仅用 50 个独特优化示例；对智能体运行时变化稳健，目标模型自用于技能生成与精炼时也有效。这是\"在预算内高效进化技能\"的精简方案。

📎 arXiv: [2609.11682](https://arxiv.org/abs/2609.11682)
