### 🧠 RNF213 直接泛素化糖原：大脑多聚葡聚糖的质量控制新机制
**Quality control of glycogen through direct ubiquitylation by RNF213**
*Nature (2026)*

生物大分子的质检多聚焦于 DNA 修复与蛋白质错误折叠，糖原这类关键储能多糖如何被细胞监控长期不清；异常的、分支稀少的糖原会聚成不溶性多聚葡聚糖体（polyglucosan）并引发严重脑病。本文发现一套此前未识别的"糖原自噬"质控通路：E3 泛素连接酶 RNF213 选择性泛素化异常糖原，再招募自噬受体 SQSTM1、TAX1BP1 与 optineurin 进入自噬体降解；缺失 RNF213 连接酶活性的小鼠在小脑、脑桥、海马堆积多聚葡聚糖。冷冻电镜表明 RNF213 的 CBM20 结构域结合线性寡糖，且遗传上位分析将 RNF213 置于 LUBAC 上游，提示一层由多个 E3 连接酶协同执勤的糖原质控网络。

📎 DOI: [10.1038/s41586-026-11139-6](https://doi.org/10.1038/s41586-026-11139-6)

### 🧩 编码性＋非遗传蛋白质变体：人类功能蛋白质组的新维度
**Encoded and non-genetic protein variants expand human functional proteome**
*Nature (2026)*

中心法则的每个环节——杂合性、体细胞突变、转录错误、翻译错误——都在为蛋白质组贡献多样性，但此前缺乏系统化的检测、定量与功能评估方法。本文基于 29 个健康组织的蛋白质基因组大数据，鉴定出 13,910 个可靠定位的变体，对应 7,215 种单一氨基酸替换，并与各自的参考蛋白同时共存。研究显示非遗传（翻译错误产生）替换的丰度与人群等位基因频率相平行，且可绕过遗传密码本身的突变约束、为探索蛋白质序列空间提供一条独立路径；氨基酸饥饿时癌细胞系还呈现出特异的、可重复的非遗传变异模式。作者据此提出这些替换构成一类新的人体蛋白“扩展形态”，为理解蛋白质组多样性提供了可量化的框架。

📎 DOI: [10.1038/s41586-026-11124-z](https://doi.org/10.1038/s41586-026-11124-z)

### 🦗 重构侏罗纪声景：远古森林已存在超声波通讯
**Reconstruction of an extinct soundscape reveals ultrasonic communication in the Jurassic**
*PNAS (2026)*

恐龙等脊椎动物的发声器官极少在化石中保存，但节肢动物硬化的角质层中负责发声的摩擦器官却容易化石留存。作者在雄性蟋蟀及其近缘直翅目物种的化石前翅上观测到"音锉—刮片"（file–plectrum）结构——它们记录了化石个体当年发出的声学信号指纹。通过整合基于系统发育的信号频率推断、化石前翅振动重建与时序模式复原，研究重构出侏罗纪森林的声音景观，揭示早期昆虫之间已经演化出超声波通讯。这项工作把声学生态学推进到化石深时间尺度，让我们得以"听见"远古生态的声音一角。

📎 DOI: [10.1073/pnas.2615107123](https://doi.org/10.1073/pnas.2615107123)

### 🌋 重思海底热泉与生命起源：对"碱性热泉假说"的修正
**Rethinking the origin of life at seafloor hydrothermal vents**
*PNAS (2026)*

自二十余年前发现以来，"碱性热泉假说"一直在生命起源假说中占重要位置：它主张蛇纹石化系统硫化物矿物膜上形成的强质子梯度，驱动了远古烟囱中原始细胞的化学渗透能量采集。本文结合近年来对太古宙海底系统地质性质的新认识提出修正：古老的蛇纹石化系统环流更浅、喷口更分散且持续更短，而 Lost City 型流体须先经冷却才呈超高碱，因此现代与古代蛇纹石化系统都不具备强的 pH 梯度。作者据此挑战"质子梯度是热泉起源必要条件"的主流推理，主张以更严格的化学约束重新评估热泉环境在生命起源中的角色。

📎 DOI: [10.1073/pnas.2613108123](https://doi.org/10.1073/pnas.2613108123)

## 🤖 AI前沿

### ⚡ GPT-6 Astra 做器件设计：AI 驱动的二维 CFET 电热协同优化
**AI for Science with GPT-6 Astra: Thermal Design and Electrothermal Analysis of 2D CFET**
*arXiv:2609.17123 (2026)*

文章把热优化问题放进一个已经建立好的电热模型中，用 AI 智能体工作流对二维 CFET 反相器做结构方案的电热协同评估：在 12 纳米尺度，Astra 选择了重新分布的源—互连几何，同时一个协调 Agent 提出衬底导向的散热方案。这类“AI for Science”多智能体流程展示出在真实半导体器件设计里定位结构与热约束折衷的能力——不是拿模型泛泛谈科学，而是落到具体器件的可验证工程任务。

📎 arXiv: [2609.17123](https://arxiv.org/abs/2609.17123)

### 🧠 ThinkFlow：可自进化的概率潜在记忆助力终身对话
**ThinkFlow: Self-Evolving Probabilistic Latent Memory for Lifelong Conversational Agents**
*arXiv:2609.17010 (2026)*

现有显式文本记忆管线常受信息瓶颈制约，容易丢失对话中细微的行为模式与情绪变化，且部署后往往静态、无法自主适应。ThinkFlow 改用可进化的概率潜在记忆：在隐空间自监督地捕获长期对话中的行为与情绪动态，让终身对话智能体能够持续更新记忆、随交互自我演化。它为构建真正"越聊越懂"的长期记忆系统提供了一个不同于文本摘要的表示方向。

📎 arXiv: [2609.17010](https://arxiv.org/abs/2609.17010)

### 🗂️ RepoAtlas：用演化多模态仓库视图引导编码 Agent
**RepoAtlas: Guiding Coding Agents via Evolving Multimodal Repository Views**
*arXiv:2609.16936 (2026)*

仓库级 issue 解决的核心难点在于：Agent 除了要生成合理补丁，还要在相互依赖的多个文件中定位相关代码，并维护既充分又聚焦的仓库上下文。RepoAtlas 通过演化的多模态仓库视图来引导编码智能体，把跨文件定位与上下文组织转成更可用的表征，缓解"补丁容易、定位和上下文难"这一当前编码 Agent 的主要瓶颈，也探索了训练后的仓库表示自适应更新。

📎 arXiv: [2609.16936](https://arxiv.org/abs/2609.16936)

### ✂️ SKIP：自知识引导的分步偏好学习压缩 CoT 推理
**SKIP: a Self-knowledge-guided Step-wise Preference Learning Framework for Concise Reasoning**
*arXiv:2609.17019 (2026)*

虽然 CoT 证明有效，但它常导致"过度思考"，带来不必要的计算开销、推理延迟，甚至性能下降。SKIP 用自知识引导的分步偏好学习，让模型在压缩输出长度的同时尽量压低准确率损失，缓解"简洁与准确不可兼得"的经典权衡。这是把推理压缩当作偏好对齐问题来处理的一次务实尝试，对降低大模型推理成本具有实际意义。

📎 arXiv: [2609.17019](https://arxiv.org/abs/2609.17019)

### 🔗 跨标准 LoRA 适配器的共享前缀 KV 复用：质量与服务的权衡
**Shared-Prefix KV Reuse Across Standard LoRA Adapters: Quality and Serving Tradeoffs**
*arXiv:2609.17109 (2026)*

一种常见的小模型部署方式是用一个共享主干承载多个 LoRA 专家、在同一上下文中作答，但朴素的服务实现会为每个专家重复预填充这段共享上下文。本文研究的是一组务实问题：对已经训练好、且未为缓存兼容做过改造的标准 LoRA 适配器，做共享前缀 KV 缓存跨适配器复用，会带来多少任务质量损失、又能多大程度改善吞吐与显存。结果给出了可操作的质—量权衡，为生产环境中的多 LoRA 缓存策略提供依据。

📎 arXiv: [2609.17109](https://arxiv.org/abs/2609.17109)
