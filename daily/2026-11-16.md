### 🧫 管腔型乳腺癌里藏着一群「表观遗传上的基底样细胞」：跨患者守恒，还能在血里查出来
**Epigenetic heterogeneity in breast tumours informs diagnosis and prognosis**
*Nature (2026)*

乳腺癌按基因表达分为管腔型与基底样，后者预后更差；单细胞技术又显示肿瘤内部高度异质。作者用基于**飞行时间流式（CyTOF）的单细胞表观遗传方案**，直接测**未经治疗、术后即刻取得**的人管腔型肿瘤，找到一个**跨患者反复出现的基底样细胞亚群**，其**表观遗传特征在患者间守恒**——用**全基因组 DNA 甲基化解卷积**在 bulk 数据里也能独立识别出同一群细胞。这群细胞**高表达侵袭性致癌性状、下调激素受体信号**；把单细胞蛋白与基因组层面的 **H3K4me1 / H3K4me3** 做直接比较后，这两类组蛋白修饰被认定为**「管腔身份丢失」的关键标记**。更实用的一步是把同一套读数搬到血里：对**游离核小体上的组蛋白修饰做单分子并行检测**，可作为**表观遗传液体活检**用于早期诊断，且血中测得的「表观基底样特征」与**预后相关**，能挑出**复发风险更高**的患者。要点是：**亚型不只在转录层存在，在表观层就被写死了；而「写死」的东西能在血浆里被读到。**

📎 DOI: [10.1038/s41586-026-11230-y](https://doi.org/10.1038/s41586-026-11230-y)

### 🧬 白血病是怎么「提前十几年」注定的：早期驱动慢、后期驱动快 100 倍，克隆横扫发生在确诊前几十年
**Evolutionary dynamics in the years preceding acute myeloid leukaemia**
*Nature (2026)*

癌症前驱演化缺的是**定量规则**，而不缺定性叙事。作者利用一批**年度采血、最长连续十年、最早始于确诊前 15 年**的系列血样，用**深度双链测序 + 演化理论**，量化急性髓系白血病（AML）关键驱动事件的**获得年龄**与**适应度效应**。读数给出一个干净的两段式图像：**第一批驱动突变多在人生前几十年获得**，此时血液仍**高度多克隆**、这些早期克隆**长得极慢**；随后这些慢克隆**再叠加多个驱动突变**，新增突变的**选择优势最高可达早期驱动的 100 倍**。携带多个驱动、长得快的克隆能在**确诊前几十年就造成血液的完全「体细胞横扫」（somatic sweep）**，而这一特征**与未来发生 AML 强烈相关**。作者据此主张：血液克隆动力学可由**一组相当简单的演化规则**描述，处于**随机与决定论之间**的平衡。含义有两层：**筛查的时间窗可能比想象中宽得多**（横扫在确诊前几十年已完成，意味着可在「横扫发生」这个节点上做风险分层）；以及**突变先后顺序的权重极不均匀**——后面那一步才是加速器。

📎 DOI: [10.1038/s41586-026-11269-x](https://doi.org/10.1038/s41586-026-11269-x)

### ⚡ 拆掉线粒体的「蛋白进口口」反而让肿瘤更显眼：mtDNA 外逃经 cGAS–STING 拉高 MHC-I，与 checkpoint 阻断协同
**Mitochondrial protein import defects enhance tumour immunogenicity**
*Nature (2026)*

肿瘤逃避免疫的常见手法之一是**压住抗原呈递**。线粒体已被当作增强抗肿瘤免疫的靶点，但**上千个线粒体蛋白**里谁在调节免疫几乎没被系统扫过。作者发现：**线粒体蛋白进口机器出问题会提升肿瘤免疫原性**，并与**免疫检查点阻断**在黑色素瘤模型中协同。具体链条是：敲低 **TIM23 进口复合体亚基 TIMM50** → **线粒体 DNA 外逃** → **cGAS–STING 通路激活** → 分泌 **IFNβ** → 经 **I 型干扰素受体**走 **JAK–STAT** → **MHC-I 上的抗原呈递增加**。外逃的 mtDNA 与**线粒体来源囊泡（MDV）**的形成有关：敲低参与 MDV 形成的 **SNX9 与 RAB9** 即抑制这条 mtDNA 依赖的 I 型干扰素产生与信号。逻辑上的价值在于：**这是把「代谢细胞器」当成「免疫可见度的调节旋钮」**——不需要引入外源抗原，只要让本该被清掉的 mtDNA 留在胞质里，就能把「自己人」的信号变成「危险」信号。对治疗的启示是**先制造免疫可见性，再用 checkpoint 阻断收割**，而不是反过来。

📎 DOI: [10.1038/s41586-026-11249-1](https://doi.org/10.1038/s41586-026-11249-1)

### 🧪 双核铜酶被改造成「自由基卤化车间」：溴、氯、异硫氰化都能对映收敛，非血红素铁酶做不到
**A binuclear copper enzyme platform for enantioconvergent radical (pseudo)halogenation**
*Nature Chemistry (2026)*

天然铜酶在新自然（new-to-nature）反应上长期被低估。作者系统评估了多类铜酶在**氧化还原活性酯的脱羧叠氮化**中的表现，发现 **III 型双核铜酶**——尤其是**巨大芽孢杆菌酪氨酸酶（BmTyr）**——对**稳定与不稳定烷基自由基**都表现出更优活性与对映选择性；经进一步工程化后，双核铜体系**强卤离子结合能力**使此前**改造后的非血红素铁酶无法实现**的**对映收敛溴化、氯化与异硫氰化**成为可能。**EPR 与紫外—可见光谱**确认了野生型与工程化细菌酪氨酸酶的**偶联双核本质**，并给出活性增强的来源线索。这篇的方法论意义大于单个反应：**「双核」提供了单核金属酶给不出的两件事——两个金属中心的协同电子转移，以及把卤离子牢牢抓住的第二个位点**，于是「自由基中间体 + 卤源」这对本来互斥的需求可以同时满足。对合成的直接用处是：**从外消旋或混杂构型的原料一步拿到单一构型的手性卤代物**，而卤代物正是后续交叉偶联最常见的「接口」。

📎 DOI: [10.1038/s41557-026-02292-6](https://doi.org/10.1038/s41557-026-02292-6)

### 🔬 把硅双量子点当分子做光谱：从「原子型能级」到「分子型成键/反键态」的转变被直接拍下来
**Directly visualizing the energy level structure of quantum dot molecules**
*Nature Communications (2026)*

硅量子点靠**轨道、自旋、谷**三种自由度支撑多种自旋量子比特操作，但在**大参数空间**上把能级谱探清楚一直很难。作者展示了一种**光谱学技术**，把**双量子点能级结构**测绘成**能级失谐、点间隧穿耦合、磁场**三个变量的函数。在**单电子区**，随隧穿耦合增强，**孤立量子点的原子型能级直接过渡为分子型的成键/反键态**；磁场下进一步**分辨基态与激发谷态各自的塞曼分裂**；在**双电子区**则拿到**依赖失谐的单—三重态劈裂**。作者指出该手法可推广到**强自旋轨道耦合材料**或**邻近耦合（proximitized）量子点**等更广体系，用来**直接提取各类能隙**。意义在方法论：通常要改器件、改栅压、跑一套拟合才能间接推断的能谱，现在变成**一张可扫的谱图**——这既是自旋量子比特标定的加速器，也是把「量子点分子」当成真正的分子来读的入口。

📎 DOI: [10.1038/s41467-026-79672-6](https://doi.org/10.1038/s41467-026-79672-6)

### 🗂️ 让「记忆值多少钱」变成可测量的信号：CoReMem 在 ChainSWE 上把 27B 智能体解决率从 21.0% 提到 25.7%，步数还少 17%
**CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation**
*arXiv:2611.17316 (2026)*

编码智能体在同一个持续演进的仓库上接续做任务，**必须在下一个任务还不知道的时候就写好记忆**——于是「为未知未来存什么」天然是个**成本—收益判断**：写要花钱、读要花钱、不写未来会重复摸索。CoReMem 把这个判断**内生化**成可测的量：**前瞻性片段估值**在**同一继承仓库状态**下，分别带/不带某段轨迹片段跑下一个任务，比较结果；由此指导构建一份**围绕锚点（仓库位置 + 可执行检查）组织的紧凑记忆**。第二步是**让执行者适应记忆**：在 rollout 组内比较带记忆与不带记忆的表现，估计**on-policy 记忆价值**，奖励优先看**是否解决问题**、并在成功 run 里**惩罚步数**；再做**出处门控的价值归因**——只把额外价值项记到「被识别为使用了记忆锚点」的步骤上，同时每步保留结果信用。读数：ChainSWE 上 **27B 执行者解决率 21.0% → 25.7%**，相对「无记忆、未训练」的执行者**步数少 17%、含记忆模块调用的总缓存感知 token 少 11%**。这条的价值在于**给出「记忆有用性」的操作化定义**：不是「存了多少」也不是「检索命中率」，而是**同一状态下有它/没它，下一个任务的结局差多少**。

📎 arXiv: [2611.17316](https://arxiv.org/abs/2611.17316)

### 🎰 「更强的模型」并不稳定地写出更好的启发式：Ballad 用老虎机在模型池里换手，追平事后最优、API 成本最多降 65.6%
**Ballad: Bandit-Based LLM Routing for Automated Heuristic Discovery**
*arXiv:2611.17241 (2026)*

自动化启发式发现（AHD）普遍假设**模型越强越贵，产出的启发式越好**。作者在**多个 NP 难组合优化问题**上直接推翻这个假设：**更大更贵的模型没有一致优势**。于是真问题变成：手里有前沿模型 + 免费/开源模型的混合池，**每一步该叫谁**。难点在于（1）**最优模型会在一次运行过程中漂移**，（2）**一个模型的输出会成为后续调用的上下文**，所以各模型的奖励信号**非平稳且彼此纠缠**，经典在线决策的独立性假设不成立。Ballad 的做法是：一个**偏好「罕见高分」而非稳定均分**的模型选择策略、沿**启发式种群谱系做 DAG 式信用传播**、以及**对陈旧观测打折**以跟上每个模型的「当前」效用。在**五个 NP 难问题 + 四个能力/成本各异的模型**上，Ballad **追平事后看最优的单个模型**，并在若干情形下**超过所有单模型**，同时相对「永远用最强模型」**API 成本最多降 65.6%**。可迁移的洞察是：**模型池的收益来自「换手时机」，而不是来自「挑选最强」**——这与模型路由的一般结论不同，因为这里每一步的输出会改写后续问题的形态。

📎 arXiv: [2611.17241](https://arxiv.org/abs/2611.17241)

### 🧠 视觉基础模型其实是个脑电基础模型：把 EEG 画成图给冻结的 ViT 看，八个数据集全胜专用模型，可训练参数每视图 ≤1,113
**Your Vision Foundation Model Is Secretly an EEG Foundation Model**
*arXiv:2611.17031 (2026)*

EEG 基础模型动辄用数千小时记录预训练，但**冻结特征迁移很差**，而且**模型更大、数据更多并不稳定变好**。作者的结论很反直觉：**一个从没见过 EEG 的视觉基础模型，只要把信号渲染成图像，就是更强的冻结 EEG 编码器**。方法 **SeeEEG** 保持视觉骨干**完全冻结**，只学「EEG 怎么显示给它看」：**每个通道占一行 patch**，画成**固定增益的波形**或**频率范围正好铺满 patch 高度的尺度图**，让任务相关模式落进**单个 token**；**导联布局、滤波、对比度**这些显示参数从**标准临床导联**初始化，再通过冻结骨干用任务损失优化——**每视图最多 1,113 个可训练参数**。对比 **7 个 EEG 基础模型、8 个数据集**（临床、睡眠、情感、脑机接口），全部**编码器冻结 + 相同读出头**：冻住的 **DINOv3 ViT-B** 在**全部八个数据集上平衡准确率都超过每一个 EEG 基础模型**，Cohen κ 或 AUROC 的平均排名 **1.3 vs 最强基线 REVE 的 2.9**；学到的「显示方式」**无需再优化即可迁移**到视频编码器 **V-JEPA 2.1**，后者在**八个数据集中六个**上两项指标都超过所有 EEG 基础模型。把 DINOv3 换成**随机初始化的 ViT-B**，分数平均掉 **15.2 分**——所以「读得懂渲染后的 EEG」这项能力**来自视觉预训练本身**。含义：**领域基础模型可能一直在为「表示形式」付学费，而这笔学费视觉预训练已经交过了。**

📎 arXiv: [2611.17031](https://arxiv.org/abs/2611.17031)

### 🧾 智能体会写布局，但写不对：模拟电路版图基准 91.1% 能产出 GDS，只有 23.0% 通过验收
**AnalogLayoutWorld: An Open Benchmark for Agentic Analog Layout Design**
*arXiv:2611.16991 (2026)*

编码智能体在软件工程上很强，但**受物理约束支配的长时程工程任务**几乎没被量化测过。作者选了**模拟电路版图**这个硬场景：需要领域知识、几何推理，还要**反复与设计和验证工具交互**。**AnalogLayoutWorld** 给出 **40 个经专家评审的任务**（从固定的晶体管级网表出发做端到端版图生成），配**集成设计环境 + 独立的物理与版图后电学验证**，以及**与版图专家共同设计的客观版图质量指标**。横跨 **13 种模型—harness 组合**的读数很锋利：**91.1% 的尝试能产出 GDS 版图，但只有 23.0% 满足验收标准**——也就是说，**「能出图」和「能用」之间隔了 4 倍**。作者自研的智能体系统 **Novara** 拿到最高综合分；进一步分析把差异归到**固定预算下的 test-time scaling**：**推理效率**与**对验证反馈的有效利用**决定了任务变复杂时质量能否守住。这条补上了「智能体在软件上强」容易被误推为「在工程上也强」的缺口：**软件里可执行即正确，硬件里可执行只是起点**。

📎 arXiv: [2611.16991](https://arxiv.org/abs/2611.16991)

### 🕵️ 「引了但没用」：1.2%–15.7% 的可引主张其实来自参数记忆，而 NLI 核查的判别力与随机猜测无异
**Cited but Unused: Parametric Provenance in Retrieval-Augmented Generation**
*arXiv:2611.17161 (2026)*

RAG 系统给每个主张挂引用，但这些引用**经常标错来源**，而**标准核查方法查不出来**。作者用**反事实值替换**测出处：把检索段落里的某条事实换成**假变体**再重问模型——如果答案不跟着变，说明这条主张其实来自**参数记忆**。结果：在**同族五个规模 + 第二个对照族**上，**1.2% 到 15.7%** 的可引主张源自参数记忆而非检索上下文；在**最保守的替换距离**下，两个被测模型是 **4.6% 与 8.5%**，且**在同一族内比例随模型变大而上升**。更麻烦的是：**自然语言推断（NLI）核查**——标准做法——给出的结果**跨模型与随机猜测不可区分**，即使**只在被引段落内**做也不行。作者把原因定位为**结构性**：**从记忆作答的模型会挑一个与自己输出相容的引用**，于是引用与答案自洽、无从判别。比较 **10 种归因方法**后，**「有上下文 / 无上下文两种分布之差」最能分离出处**；但**在这些基础比例上按该信号行动并不能提升出处的诚实度**——检测器仍在测**「模型知道什么」而不是「模型用了什么」**，把二者分开仍是开放问题。

📎 arXiv: [2611.17161](https://arxiv.org/abs/2611.17161)
