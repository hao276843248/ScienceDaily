### ⚛️ 自主量子纠错越过盈亏平衡点：只靠驱动与耗散，逻辑比特寿命达到系统里最好物理比特的 1.04 倍
**Extension of coherence time beyond breakeven point using only drives and dissipation**
*Nature Physics (2026)*

现有纠错实现大多依赖**测量+经典反馈**，但读出保真度、硬件延迟与系统复杂度限制了它的可扩展性。**自主量子纠错**走另一条路：不测、不反馈，只靠工程化的**驱动与耗散**把熵抽走。作者实现的协议来自**量子信道模拟**——它把光子丢失造成的错误信息**转移到辅助比特再重置辅助比特**，因此原则上**适用于任意恢复映射**，而不是像早期演示那样只为某个码定制哈密顿量与耗散来**稳定一个流形**。在长寿命玻色模式上用**二项码**编码，逻辑比特相干时间被延长到系统中最优物理比特的 **1.04 倍**——第一次用「只有驱动与耗散」把纠错后的玻色逻辑比特推过盈亏平衡点。

📎 DOI: [10.1038/s41567-026-03528-5](https://doi.org/10.1038/s41567-026-03528-5)

### 🔋 给石墨–硅复合电极拍「四维化学力学」：决定局部反应的是快离子通道，不是电极深度
**Four-dimensional X-ray nano-holotomography reveals multiscale chemomechanics in composite graphite–silicon battery electrodes**
*Nature Nanotechnology (2026)*

把**电极微结构**和**电化学性能**对上号，需要在极限时空尺度上做**机理性的四维观测**，此前做不到。作者用**中断式原位同步辐射 X 射线纳米全息断层成像**配**数字体相关（DVC）**，在**颗粒（局部）与电极（平均）两级尺度**同时追踪化学力学演化，对象是**石墨–硅复合电极的首圈化成**。结论是局部电化学活性与不可逆性同时受**局部离子扩散性质、石墨颗粒形貌与在电极中的位置、到硅团簇的距离、与电解液的表面接触、机械形变**影响，但**这些因素并不等权**；其中被识别出的**快离子扩散通道**起关键作用，**抵消了由离子/电子扩散限制造成的深度依赖反应不均**。作者给出了一条**按影响力排序**的框架，把「超出集合平均」的结构因素逐项分级。

📎 DOI: [10.1038/s41565-026-02327-6](https://doi.org/10.1038/s41565-026-02327-6)

### 💠 卟啉纳米带在电中性态就出现全局反芳香环流：72、96、120 π 电子的 Hückel 回路
**Globally antiaromatic anthracene–porphyrin nanobelts**
*Nature Chemistry (2026)*

共轭分子带（molecular belt）的 p 轨道沿径向排布，理论上应像**量子环**一样出现**全局芳香/反芳香环电流**；但绝大多数烃基苯环带里**定域的 Clar 六元环**把全局环流压掉了，宏观环流从未在电中性态出现。作者合成**蒽桥连的卟啉纳米带**：用 **Ni(0) 介导的 Yamamoto 偶联**完成大环化，再靠**给电子甲氧基促进的 DDQ/TfOH Scholl 氧化**关环，得到**张紧的三股纳米带**。¹H NMR 显示它在**中性态**就具备**全局反芳香性**，对应 **72、96、120 π 电子**的 Hückel 回路，计算独立支持。要点：把「必须靠氧化还原才能翻转的全局环流」变成**中性态就存在**的性质，并给出了一条在烃基纳米带尚不可合成时先用杂环搭平台的路线。

📎 DOI: [10.1038/s41557-026-02302-7](https://doi.org/10.1038/s41557-026-02302-7)

### 🔌 二维晶体管的高温栅介质：Bi₂MoO₆ 单晶纳米片 κ=54.2、击穿 3.9 MV/cm，500 K 下开关比仍 >10⁴
**High-κ bismuth molybdate single-crystalline dielectric for high-temperature two-dimensional transistors**
*Nature Communications (2026)*

二维半导体是后硅器件的候选，但用现有高 κ 介质集成**高温**二维器件仍卡住。作者用 **BiOCl 辅助化学气相沉积**长出**厚度可控、热稳定性好**的**钼酸铋（Bi₂MoO₆）单晶纳米片**，室温测得**高 κ（54.2）**、**宽带隙（约 3.85 eV）**与**大击穿场（约 3.9 MV/cm）**。用它做顶栅 MoS₂ 晶体管：**迟滞可忽略**，在三个数量级电流范围内**平均亚阈值摆幅 <100 mV/dec**，工作稳定性好；升温到 **500 K** 仍保持 **>10⁴ 的开/关比**、迟滞 **<10 mV/(MV cm⁻¹)**。以该介质做的反相器在 **5 V** 供电下增益 **86.1**。要点：高温二维电子的瓶颈常常不在沟道而在**介质的热稳定性与界面**，这里给了一个可长、可栅控的单晶高 κ 选项。

📎 DOI: [10.1038/s41467-026-79576-5](https://doi.org/10.1038/s41467-026-79576-5)

### 🪞 双层超表面：同一套 meta-atom 既做相移又做阻抗匹配，反射压到裸玻璃以下仍保持衍射极限聚焦
**Antireflective bilayer metasurfaces with complete wavefront control**
*Nature Nanotechnology (2026)*

减反膜靠**匹配界面光学阻抗**提高透过；把这套思路搬到超表面很难，因为波前控制依赖**几何各异的 meta-atom 阵列**，等效于一个**空间变化的阻抗**。作者用**垂直集成**绕开这个矛盾：让**双层 meta-atom 同时充当移相器与阻抗匹配叠层**。他们把 meta-atom 当**多层薄膜**处理，推出把**两层独立图案化的有效折射率**联系起来的**设计规则**，并据此筛出**覆盖完整 0–2π 透射相位**的减反双层库。演示件是 **1310 nm** 工作的**自支撑 TiO₂/TiO₂ 超透镜**：反射**低于裸玻璃**，同时保持**衍射极限聚焦**。要点：把「阻抗匹配」和「相位覆盖」从两个互相牵制的设计目标，变成**同一 meta-atom 的两个自由度**。

📎 DOI: [10.1038/s41565-026-02330-x](https://doi.org/10.1038/s41565-026-02330-x)

### 🧮 把 CPU 编译进 LLM 权重：零梯度、零样本、零运行时钩子，6 位数算术 100%，而 1.28 万样本 LoRA 只有 42–62%
**A CPU Inside an LLM: Zero-Gradient Compilation of Exact Circuits into Pretrained Weights**
*arXiv (2026)*

预训练语言模型不做梯度微调、不调外部解释器时，**多位数精确算术**一直不可靠。作者提出**闭式、零梯度的电路嫁接原语**：**零训练样本、零运行时钩子**，把确定性计算**直接编译进预训练权重**，同时给逐层归一化漂移定界并保住自然语言能力。三个解析机制是关键：**基于 Mellin-GLU 求积的两层构造**把未知的逐 token RMSNorm 缩放变成**对数间隔门网格上的平移**（>250× 动态范围，带 IEEE 754 误差界）；**跨 token 尺度抵消**靠带符号 Chebyshev 不定 RoPE 自汇注意力与无记忆 SiLU 反对称 GatedDeltaNet 位移；**轴对齐宽度扩展**（d→d+K，√(d/(d+K)) 范数补偿）配 **Base-1000 规范 BPE 输出**与差分绑定反嵌入。一个**五阶段编译器**以**常数 TC⁰ 深度**合成 4–8 位带符号加减乘电路，以及三文字布尔（100%，N=1,728）与 5 位 Majority/Parity（100%）电路；6 位数算术（N=1,200，BF16）上 **Granite 4.2 3B 达 99.17%、Qwen 3.5 4B 达 100.00%** 的 ALU 前缀准确率（FP32 sidecar 补到 100%），句中续写 98–100%，而 **12.8K 样本 LoRA 只有 42.2%/61.7% 且无法句内接续**；改动参数占比 **≤0.036%/≤0.057%**，A100 显存 7.89/10.65 GiB。要点：**「模型不会算」可以被当作编译问题而不是学习问题**——精度来自结构注入，不来自样本量。

📎 arXiv: [2611.26450](https://arxiv.org/abs/2611.26450)

### 🤖 5 万小时人体全身运动预训练：人形机器人 8 项任务平均成功率 93.75%，超过 GR00T N1.7 与 π0.5
**Awaken-HI: Scaling Humanoid Intelligence with Whole-Body Human Experience**
*arXiv (2026)*

现有第一视角视频覆盖了很多人做的日常活动，但**缺少同步的全身运动数据**，没法大规模学**移动+操作**。作者构建 **Awaken-Human**：约 **5 万小时第一视角立体视频**配**同步全身人体运动**，覆盖 **100 多种技能**；在此之上提出 **Awaken-HI**——一个面向人形**移动操作**的 VLA 模型，通过**共享动作专家**同时预测**原始人体运动**与**重定向后的机器人动作**。核心结论是：**人体轨迹直接监督共享动作专家**时，技能从人到人形机器人的迁移更有效；增加人体预训练数据会**按一条经验缩放律降低留出的机器人动作预测误差**，并抬高下游真机任务成功率。全量预训练 + T800 适配后，**八项单任务平均成功率 93.75%**，在单任务与长时程评测上均优于 **GR00T N1.7 与 π₀.₅**，并泛化到机器人后训练中未见过的物体与新的「物体—目的地」组合。要点：**迁移的载体是「人怎么动」的显式监督，而不是更多的机器人遥操作**。

📎 arXiv: [2611.26420](https://arxiv.org/abs/2611.26420)

### 🕵️ 谎言常常不在「词」上：persona 方向大多只跟着措辞走，知识方向才偶尔分得开「撒谎」与「诚实否认」
**The Geometry of Lies: Knowledge and Persona Directions for Detecting Deception in Large Language Models**
*arXiv (2026)*

线性探针是最便宜的 LLM 测谎器，但**跨「谎言种类」不迁移**；从诚实/欺骗角色扮演里取出的**无标签方向**在 70B 规模、以及在「否认自己知道」这类**撒谎与诚实否认措辞可以完全相同**的情形下从未被检验。作者扩充了公开的 persona 库，加入**否认自己拥有的知识**的角色及其诚实对应，在每层中段取 persona 方向。结果是一份**大量负结果**：该方向在 Liars' Bench 上于四个模型中**有三个**胜过单数据集探针，**在 Qwen 上失败**（尽管 Qwen 最常保持在角色里）；在 Llama-3.3-70B 上胜过随机 persona 库，但**相对已发表方向的增益仍落在「随机扩充」的波动带内**。在关于知识的谎言上，persona 方向**主要在追踪回复措辞**——当谎言与诚实否认用词相同时，三个主对比在 Llama/Qwen 上仍在随机带内、在 Gemma 上只到带的边缘、仅 Mistral 越出。另一个**知识方向**（对比模型能答与谁都答不了的问题，后接同一句脚本化否认）在两个模型上（第三个勉强）分得开谎言与措辞相同的诚实否认，第四个不行；两者之和在**同深度的监督探针**之上排名更好（四个模型全胜，其中一个两者都接近随机），但在 Llama 的平均上只与 persona 方向持平、在留出谎言上落后该探针。要点：**「撒谎的方向」很可能不是一个统一方向**，多数所谓测谎信号量到的是**怎么说**，不是**是否知道**。

📎 arXiv: [2611.26545](https://arxiv.org/abs/2611.26545)

### 📊 自一致性早停的隐含假设：rollout 相关时，标准 e-process 只保证「这批抽样所代表的信念」，不保证模型的平均行为
**Realized versus Population Reliability: Anytime-Valid Self-Consistency Certification under Correlated Reasoning**
*arXiv (2026)*

自一致性认证把「重复采样」当作**序贯证据累积**，当 anytime-valid 的 **e-process** 越过阈值就停，靠 Ville 不等式保证有限样本下的第一类错误控制。作者指出这套构造默认 **rollout 条件独立**，而这在实践里不成立：推理流会通过**共享前缀**或**跨 prompt 异质性**正相关，于是受影响的不只是认证效率，还有**被认证的到底是哪个假设**。用**逐单元潜状态**（随机效应 / 组内相关结构）建模后，增量成为可交换、等相关的（相关系数 ρ），单个零假设被拆成**关于这批抽样信念的 realized null**与**关于模型平均行为的 population null**，二者只在 ρ=0 时重合。四条结果：标准 betting e-process 只对 realized null 保持 anytime-valid；把它当 population 检验读，合适混合的渐近越界概率至少 π=P(μ(Z)>0)，**可能超过名义 ε**；组内均值的**有效样本量饱和在 1/ρ**，多采组内 rollout **无法恢复 population 有效性**；**prompt 级 e-process** 能恢复它，且在纯 rollout 预算下最优分配是**每个 prompt 只用一次**。Claude Haiku 4.5 实测给出 regime 依赖：GSM8K 上（ρ̂=0.435，θ̂=+0.96）差距休眠；AIME 上（ρ̂=0.480，θ̂=−0.15）单单元规则在名义 ε=0.05 时于 **24% 的 prompt** 上越界，而 prompt 级程序一次也没越界（0.00）。要点：**「模型可靠」这句话必须先指定是「这批样本可靠」还是「模型平均可靠」**，后者不能靠加采样买到。

📎 arXiv: [2611.26592](https://arxiv.org/abs/2611.26592)

### 🧯 事故复现比事故目录更有用：重放 108 起 agent 事故 89% 复现，62/72 起根本没有攻击者，而「点名危险」的提醒能降低全部五个模型的伤害
**Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)**
*arXiv (2026)*

LLM agent 现在可以替用户**删文件、发付款**，媒体报道里这类事故层出不穷，但报道通常只说**出了什么事**，很少**证实或否证**这起事故、更少找到**根因**；事故目录只收集报道，基准只记录「是否失败」，两者都**不复现事故、也不检验报道指认的原因**。作者提出 **ROGUE-AI**：一个多智能体框架，把每起被报道的事故**离线重建**，并配一个**只缺「被指认原因」的对照**，然后在两者上各跑 agent。结果：**108 次复现尝试中 89% 成功重现了报道中的伤害**；基于五个当前 GPT/Claude/Gemini/DeepSeek 模型的 agent，在 **18%–33% 的运行**里犯下报道里的错误，而对照组**最多 1%**。更反直觉的是：**72 起造成真实伤害的事故里有 62 起根本不存在攻击者**——agent 做了任务要求的事，只是漏掉了一个日常隐患（例如共用了与线上站点同一个数据库）；**对全部五个模型，无攻击者的复现造成的伤害都高于 prompt injection 复现**。而针对 prompt injection 的防御找的是「注入的指令」，这些复现里**一条都没有**。作者还测了一个干预：在每次工具输出后给一条**点名危险及其后果**的警告，五个模型的伤害都下降；同等长度但**不提危险**的提示，大部分伤害依旧。要点：真实 agent 事故的主体是**普通危害的遗漏**而非攻击，能做的是**可重跑的审计**加**点名后果的运行时提醒**。

📎 arXiv: [2611.26553](https://arxiv.org/abs/2611.26553)
