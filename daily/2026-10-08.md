## 🔬 科学前沿

### ⏱️ 首个闭环运行的钍-229 核光钟
**A thorium-229 optical nuclear clock with feedback loop**
*Nature (2026)*

钍-229 原子核的 148 nm 核跃迁因可用激光直接激发，被认为是比电子壳层光钟更抗外界扰动、对基础物理检验更敏感的候选时间基准。研究团队把连续波激光锁定到嵌在毫米级室温氟化钙晶体中的 ²²⁹Th 核跃迁上，用基于吸收光谱的快速反馈实现闭环运行，并把 148 nm 辐射的次谐波与一台镱离子单钟持续比对。该核钟的分数频率不稳定度达到 3×10⁻¹²/√(τ/s)，运行一天可逼近 10⁻¹⁵；团队还用它搜寻超轻暗物质导致的周期性频率漂移。这是核光钟第一次以"带反馈环"的方式稳定运转，为下一代超高精度计时与基础常数检验打开了大门。

📎 DOI: [10.1038/s41586-026-11084-4](https://doi.org/10.1038/s41586-026-11084-4)

### 🧪 相对论让最近超重元素的金属—配体键变弱
**Observation of relativistic bond weakening in seaborgium hexacarbonyl**
*Nature (2026)*

超重元素（Z ≥ 104）的化学性质深受相对论效应影响其价电子壳层，理论预测其羰基配合物的金属—配体键稳定性会被改变，但一直缺乏直接实验证据。研究团队用气相色谱研究镤（Sg，Z=106）的六羰基配合物 Sg(CO)₆，通过测量其与 W(CO)₆ 的生成产率，首次定出 Sg(CO)₆ 的第一键解离能为 188(9) kJ·mol⁻¹——比同族的 W(CO)₆ 低 4(2) kJ·mol⁻¹，即第 6 族六羰基物键解离能"从 W 到 Sg 递增"的趋势被逆转。该结果与最先进的理论计算一致：Sg 的 6d 原子轨道相对论去稳定，导致键变弱。这是超重元素成键中相对论效应的一次干净实验验证。

📎 DOI: [10.1038/s41586-026-11105-2](https://doi.org/10.1038/s41586-026-11105-2)

### ⚡ 带隙突破 7 eV：硅掺杂 α-(AlₓGa₁₋ₓ)₂O₃ 半导体
**A 7-eV bandgap semiconductor based on silicon-doped α-(AlₓGa₁₋ₓ)₂O₃**
*Nature (2026)*

在功率电子中，带隙越宽器件效率与功率密度越高（Baliga 优值正比于 Eg^5.5），但带隙越大就越难用平衡掺杂把电导率可控地调制几个数量级——这长期是超宽带隙半导体的核心瓶颈。研究团队用亚氧化物分子束外延生长硅掺杂的 α-(AlₓGa₁₋ₓ)₂O₃ 薄膜，带隙超过 7.0 eV，超过了此前最宽带隙半导体立方氮化硼。在 >6 eV 的"巨大带隙"区间，这些薄膜的室温电导率比以往同类材料高出逾一亿倍，证明大带隙未必意味着无法调控导电性。该材料为高效、高功率密度的下一代功率器件提供了新的候选平台。

📎 DOI: [10.1038/s41586-026-11085-3](https://doi.org/10.1038/s41586-026-11085-3)

### 🦠 随人类走出非洲、正在消失的肠道微生物
**Prehistoric global migration of vanishing gut microbes with humans**
*Nature (2026)*

许多在非工业化人群中常见的肠道微生物，在工业化人群里已经消失或灭绝，但哪些是人类肠道的"长期居民"、是否与人类共同演化，此前难以厘清。研究团队对玻利维亚 Tsimane 农耕人群做了深度宏基因组测序，并与坦桑尼亚 Hadza 狩猎采集人群比对。这两个群体的祖先已分离数万年，却仍共享 1231 个微生物物种，其中大多数在工业化人群中罕见或缺失。这说明这些微生物是随人类迁徙、长期共居于人类肠道的物种；该研究为评估微生物多样性丧失如何影响健康、以及重建人类—微生物共进化史提供了关键基线。

📎 DOI: [10.1038/s41586-026-11106-1](https://doi.org/10.1038/s41586-026-11106-1)

### 🦴 侏罗纪一具会游泳的哺乳形动物，改写吞咽装置的起源
**A Jurassic mammaliaform swimmer and transformation of the mammalian pharynx**
*Nature (2026)*

中国中侏罗世出土的一具保存精美的哺乳形动物化石，为理解哺乳动物摄食装置的演化与中生代哺乳形动物的生态多样性提供了直接证据。该化石罕见地保存了类似兽亚纲的咽腔顶（咽喉通道）与舌骨（咽部骨骼）解剖，提示兽亚纲式吞咽、饮水与吮乳所需的关键软组织解剖，在齿兽类（Docodonta）与哺乳动物的共同祖先中就已经演化出来——远早于现代哺乳动物的兴起。化石同时具备一系列适应游泳的骨骼特征，填补了早期哺乳动物骨盆与后肢解剖的关键空白，其高度特化的犬齿与伪裂齿则指示食虫/食肉习性。

📎 DOI: [10.1038/s41586-026-11107-0](https://doi.org/10.1038/s41586-026-11107-0)

## 🤖 AI前沿

### 🔤 把语言模型"改装"成按字节运行
**Retrofitting language models to operate over bytes**
*Nature (2026)*

当今大语言模型普遍以子词（subword）分词把文本切分成 token，这层切分掩盖了细粒度字符信息，对代码、生物序列等"意义依赖单个字符/字节"的科学数据尤其不利；而直接按字节建模的模型此前性能一直落后于子词模型。研究团队提出一种通用的"字节化"（byteification）方法：用两阶段转换流程，把已有的子词模型改装成字节级模型，只需极少的额外训练。改造后的字节级模型性能超过以往的字节级模型，逼近子词系统的能力。这为科学数据（源代码、基因序列）提供了更贴合其结构的建模基础。

📎 DOI: [10.1038/s41586-026-11111-4](https://doi.org/10.1038/s41586-026-11111-4)

### 🛡️ AdvSim2Real：在网页世界模型里对抗"自适应提示注入"
**AdvSim2Real: Training Web Agents Against Adaptive Prompt Injection in a Web World Model**
*arXiv:2610.08773*

网页 Agent 要读取并操作第三方编写的页面，因此页面上埋入的指令可以把 Agent 引离用户的目标；而 Agent 又不能直接忽略页面，因为完成任务所需的值和控件也在页面里。现有防御在训练前把注入固定下来微调，攻击者一旦针对训练后的模型自适应调整就能绕过；对抗训练虽能让攻击者自适应，却把任务固定住，任务一旦被解决就不再提供教学价值。AdvSim2Real 在一个冻结的网页世界模型内部让三者协同进化：任务课程（只奖励 Agent 成功率约一半的任务）、注入对手（只在"把判定的成功翻转成失败"时得分）与 Agent 本身。结果一个 4B 模型在模拟器中训练后能力与鲁棒性同时提升，能抵御从未训练过的前沿模型对手，能力增益还能迁移到真实浏览环境。

📎 arXiv: [2610.08773](https://arxiv.org/abs/2610.08773)

### 📚 Sherpa：教大模型"因人施教"
**Sherpa: Teaching LLMs to Teach Adaptively**
*arXiv:2610.08778*

大模型越来越会解题，但"会解"不等于"会教"；现有把 LLM 训成教师的方法依赖示范、偏好数据或预先规定好的教学标准，这些信号往往并不扎根于具体学习者真实的学习结果，而有效的教学策略又因学习者而异。Sherpa 是一个多轮强化学习框架：它用 LLM 实例化出多个具有不同学习偏好的"学生原型"，再训练教师模型通过直接最大化这些学生的学习成果来调整自己的讲解方式。被 Sherpa 训练出的教师模型在所有学生原型上平均把学生成绩提升了 20.5 个百分点；在 MathTutorBench 上，整体教学评分从 52.5% 提升到 79.2%，人类研究也显示受训教师更受偏好。

📎 arXiv: [2610.08778](https://arxiv.org/abs/2610.08778)

### 🍶 Agent in a Bottle：把通用能力"装瓶"成廉价可复用的方案
**Agent in a Bottle: Can LLM Agents Turn Their Capabilities Into Cheap, Scalable Artifacts?**
*arXiv:2610.08775*

大模型能解很多窄任务，但对数百万个彼此相关的实例逐一调用 API 会昂贵到不可行。论文把"Agent 能否自主为这类负载造出更便宜的解法"称为"装瓶"（bottling）：把通用能力转成任务专用方案，在答案质量与摊销成本之间取得平衡。作者提出 BOTTLED 基准——Agent 会收到一整批未标注的工作负载，必须在固定的时间、算力和 API 预算内完成，并可自行选择方法（例如训练一个小模型，或写一段可复用的程序）。在 10 个模型、3 类任务上，实验发现强的零样本表现并不能可靠地转化为强的"装瓶"能力：零样本得分相近的模型在装瓶后可能差距明显，60 次装瓶运行里有 31 次不如同等 token 预算下更强的两个小模型蒸馏基线。

📎 arXiv: [2610.08775](https://arxiv.org/abs/2610.08775)

### 🧮 WorldSolver：LLM Agent 能否靠"生成求解器"模拟物理动态
**WorldSolver: Can LLM Agents Simulate the Physical Dynamics via Solver Generation?**
*arXiv:2610.08720*

LLM Agent 正越来越多地介入科学与工程问题求解，而物理仿真是其中既有挑战性又实用的测试场：solver（求解器）负责计算动态系统状态随时间如何演化，造出它既需要物理理解以选定模型、数学推理以写出动力学方程，也需要软件工程把它实现为可执行代码——这一能力此前鲜被系统评估。WorldSolver 是一个包含 168 个仿真任务的基准，任务取自 61 篇经典计算机图形论文中的物理现象，横跨 7 个物理域；每个任务提供一个固定仿真环境的代码骨架，把求解器实现留给 Agent 补全。评估从"能否成功执行""视觉保真度"等维度进行，用来衡量 Agent 对物理世界动态的模拟能力。

📎 arXiv: [2610.08720](https://arxiv.org/abs/2610.08720)
