### 🌍 两百年泥炭地排水：0.5% 的陆地面积，贡献了 2.7% 的工业时代辐射强迫
**An enduring climatic burden from past peatland drainage**
*Nature (2026)*

泥炭地在千年尺度上从大气里抽走了数百吉吨 CO₂、又排出一部分 CH₄，净效应是缓慢降温；而人为排水让泥炭分解、把 CO₂ 重新放出来，同时**压制 CH₄ 排放**——两者方向相反，全球尺度上一直没算清净账。作者把**新的通量数据集 + 水文驱动的 CO₂/CH₄ 通量模型 + 1800–2020 年排水范围与强度的历史回推（hindcast）**拼起来，重建了全球泥炭地排水的辐射强迫：净**增温 +73（48–99）mW m⁻²**，相当于工业时代辐射强迫的 **2.7（1.8–3.6）%**，而这只来自全球陆地面积的 **0.4–0.5%**。净增温的来源是排水诱导的 CO₂ 排放（**+83（52–110）mW m⁻²**）压过了被避免的 CH₄ 排放（**−9（−15 至 −2）mW m⁻²**）。更关键的是**遗留效应**：即使排水面积不再扩大、只是把现有已排水泥炭地维持现状，到 2100 年累计增温也几乎会翻倍。这把「历史土地利用」从一笔可忽略的旧账，变成了一项仍在持续计息的气候负债。

📎 DOI: [10.1038/s41586-026-11339-0](https://doi.org/10.1038/s41586-026-11339-0)

### 📏 140 万人外显子测序：单拷贝失活变异让身高从 −17 cm 到 +11 cm
**Rare-variant genetic architecture of height in over 1.4 million individuals**
*Nature (2026)*

身高是遗传学里的模型性状，但过去二十年的成果几乎全在**常见变异**上，**罕见变异**的图景基本空白。作者在 **826,066 例外显子**里筛罕见蛋白改变变异，找到 **207 个身高相关基因**，其中 **98%** 在另 **624,567 人**中重复出来。最罕见也最有害的一类——**单拷贝（频率 <0.0001%）推定功能缺失变异**——点名了 **17 个效应巨大的基因**，每个等位基因的效应从 **−17 cm（ACAN）到 +11 cm（FBN1）**，是常见身高变异平均效应的 **52 倍**，量级相当于常见变异多基因评分的**前 1% 尾部**。其中 **TET1、DTL、IGF2BP2** 的效应量至少与已知孟德尔身高基因相当，却**没有**任何已记录的身材或骨骼生长综合征——尤其是那些**增加**身高的基因。这说明「有大效应」不等于「有临床表型」，对性状预测、临床评估和以身高为切口找药物靶点都有直接影响。

📎 DOI: [10.1038/s41586-026-11345-2](https://doi.org/10.1038/s41586-026-11345-2)

### 🫀 44 条人冠状动脉的单细胞「变异→增强子→基因」地图：AMOTL2 被点名
**Single-cell variant-to-enhancer-to-gene map for coronary artery disease**
*Nature (2026)*

冠心病 GWAS 已找到数百个位点，但绝大多数变异落在**非编码区**，究竟是**哪种细胞、哪个基因**在起作用长期模糊。作者对 **44 人**的冠状动脉做**单核 RNA + 染色质可及性多组学**，构建全基因组范围的**单细胞变异—增强子—基因（V2E2G）图谱**，在主要血管细胞类型（含**平滑肌细胞 SMC**）里鉴定 **11,269 个染色质可及性定量性状位点（caQTL）**，其中含冠心病相关位点。用**动态单细胞 caQTL 建模**发现变异效应**随 SMC 状态而变**：例如 **rs658956** 通过破坏 **AP-1 基序**压制 **FGGY-DT** 增强子，而这种压制在 SMC 向**纤维肌细胞（fibromyocyte）**命运转变时被**放大**。作者又在 **15 条**冠状动脉做全基因组 **Hi-C**，显示 **ADAMTS7** 冠心病位点上的 **rs4887091** 对 **CTCF** 占据与染色质环强度有**等位基因依赖**效应；整合 Hi-C、HiChIP 与体外 **CRISPRi** 后，把 **AMOTL2** 提名为一个**远端、SMC 特异**的冠心病基因——它的缺失促增殖、抑制收缩身份。这把非编码 GWAS 信号落到了**具体细胞状态 + 具体远端靶基因**上。

📎 DOI: [10.1038/s41586-026-11275-z](https://doi.org/10.1038/s41586-026-11275-z)

### 🧬 I-F3 型 CAST 的「许可」机制：零样本重设计 TnsA，整合活性提升近百倍
**Licensing mechanisms during RNA-guided DNA integration by type I-F3 CAST**
*Nature (2026)*

把**大片段 DNA 精确定点整合**进基因组仍是基因工程的核心难题；CRISPR 相关转座酶（CAST）把 RNA 引导的靶向识别接到转座整合上，是热门解法，其中 **I-F3 型 CAST** 因靶向保真度极高而受关注，但其**结构基础一直不清**。作者以**霍乱弧菌 CAST（VchCAST）**为对象，用**冷冻电镜 + 计算蛋白设计 + 功能实验**解出**全酶整合复合体**结构：结构测定本身是靠对 **TnsA 做零样本计算重设计**才拿到的，而这次重设计顺带把整合活性提高了**近两个数量级**、且不损特异性。结构显示一套**构象「许可」事件**控制整合机器在**在靶位点**的激活：**Cascade–TniQ、TnsC、TnsA–TnsB** 在装配成全酶复合体时各自发生构象变化，**只有完整装配态**才稳定住催化 competent 状态。与已有 CAST 复合体结构比较显示**架构特征保守**，提示 RNA 引导转座在各型 CAST 间有**共同分子基础**——这既给了机制框架，也示范了「用蛋白设计反过来解锁结构生物学」。

📎 DOI: [10.1038/s41586-026-11287-9](https://doi.org/10.1038/s41586-026-11287-9)

### ⚡ 锰掺杂量子点固体：热电子漂移近亚毫米，室温迁移率约 150 cm²V⁻¹s⁻¹
**Submillimetre hot-electron transport in manganese-doped quantum dot solids**
*Nature (2026)*

胶体量子点固体在光转换与光化学上很有前途，但被三件事卡住：**热载流子冷却太快、迁移率低、输运距离短**。作者在**锰掺杂量子点薄膜**里做出一套**自旋交换驱动**的光输运机制：**自旋交换介导的俄歇上转换**在声子冷却之前把电子推到**高能、离域**的态，形成一个**瞬态高迁移率导电通道**；更关键的是自旋交换不只**产生**热载流子，还能让它们**反复被再激发**，从而把长程漂移**维持住**。结果是在**室温**下得到约 **150 cm² V⁻¹ s⁻¹** 的迁移率与**亚毫米级漂移长度**，远超常规量子点固体、逼近晶态半导体的典型值。**飞行时间（ToF）**测量确认是**漂移主导**输运：渡越时间随距离**线性**增长、随电场**反比**下降。这给纳米材料里的长程能量输运开了一条路，也让热载流子真正可用于光转换、光化学与**渡越时间受限**的光探测。

📎 DOI: [10.1038/s41586-026-11279-9](https://doi.org/10.1038/s41586-026-11279-9)

## 🤖 AI前沿

### 🧠 同一批视觉推理题：编码 agent 写程序渲染答案，全面压过视频生成模型
**Solve Vision with Code: Coding Agents Are Stronger Visual Reasoners Than Video Models**
*arXiv (2026)*

视频生成模型正被当作**视觉推理器**来评测：给首帧 + 自然语言指令，能不能生成「任务被完成」的视频；支持者的理由是推理**直接发生在画面里**，不经语言也不经代码。但这个「原生路线更可靠」的假设，从没在**同等条件下**与符号路线对照过。作者把同一批任务、同样输入、同样输出规范、同一个评估器同时交给两种媒介：不让模型去噪像素，而是让**编码 agent 写一个程序把答案视频渲染出来**，再由**未经修改的规则评估器**打分。在 **VBVR-Pro-Bench**（500 题、五类认知任务、有符号真值）上，agent 与视频模型拿同样的首帧与提示、**看不到真值与元数据**、每题**只试一次**：三个闭源 agent 得 **0.923（Codex + gpt-6-astra）、0.894（Claude Code + Fable 5.1）、0.893（Gemini CLI + Gemini 3.1 Pro）**，每个都比最强视频模型**高 0.22 以上**；23 个可运行开源权重模型里最好的 **GLM-5 得 0.572**，除那个 RL 训练过的视频模型外**高于所有视频模型**。作者进一步区分**描绘型程序**（在图像中导航、恢复可迁移的图式）与**命题型程序**（对硬编码数值操作），用来解释视觉推理在 agent 写的代码里究竟以何种形式发生。

📎 arXiv: [2611.34813](https://arxiv.org/abs/2611.34813)

### 🕵️ 监控器到底多强？换个「攻击策略」来测，漏检率能从 0.5% 跳到 20.8%
**Attack Policy Selection can Mislead Monitor Evaluators**
*arXiv (2026)*

AI 监控器（标记 agent 危险行为的分类器）通常拿**攻击策略生成的轨迹**当部署期危险行为的**代理**来评测。作者以一个**已下线的生产级 OpenAI 监控器**为案例，发现测出来的**漏检率（FNR）**对两件事极度敏感：**用什么方法生成攻击策略**，以及**在该方法里优化到什么程度**。单靠**强化学习**一种方法，不同优化档位之间 FNR 就从 **0.5% 到 20.8%**；在各自最佳优化档位上，跨方法（**优化提示 vs 轨迹编辑**）从 **6.4% 到 23.0%**。所有攻击策略都只针对**代理监控器**开发，报告的结果全部显示能**迁移到留出的 GPT-5.4 目标监控器**。作者指出代理轨迹会引入**可见痕迹**——例如推理一个监控器提示里根本不存在的「side task」——从而影响判定；因此**只用基础攻击方法评测，会给出「监控器很强」的虚假信心**：要把某个具体结果读成对部署性能的证据，需要**额外论证这些代理为何有信息量、以及是否保守**，而目前这种论证仍是开放问题。

📎 arXiv: [2611.34934](https://arxiv.org/abs/2611.34934)

### 🎙️ μ-Bench：共享空间里的多用户语音 agent，专有系统最高 65%，开权重不到 20%
**μ-Bench: Benchmarking Multi-User Task Completion in Shared Interaction Voice Agents**
*arXiv (2026)*

共享空间里的语音 agent 要同时满足**相互纠缠的多用户请求**，还要守住**每个用户各自的权限、隐私与任务约束**；现有评测在「参与者在会话过程中不断反应」这一点上覆盖不足。作者提出 **μ-Bench**：**闭环、全双工、多用户**语音交互的联合任务完成基准。**模拟参与者**从各自独立的**目标、知识、权限**画像出发行动，并会**针对 agent 的说话与工具结果实时调整**；覆盖 **20 个领域、100 个场景**，变化**群组规模、声学条件、追问要求**，共 **800 个 case**（408 带工具、392 不带工具）。指标 **Joint Task Success（JTS）** 要求**所有用户目标、隐私边界、终止状态同时成立**，**Pure JTS** 进一步**禁止任何未授权工具调用**；**Attribution / Threading / Coordination（ATC）诊断**用来定位失败环节。13 个语音 agent 上，专有系统在**无工具 62.24%、带工具 65.44%** 见顶，**开源权重模型全部低于 20%**；ATC 显示开权重主要落后在**多轮归属（attribution）与串接（threading）**，受控对照还显示——在能力足够的系统上，**群组越大，联合成功率越差**。

📎 arXiv: [2611.34920](https://arxiv.org/abs/2611.34920)

### 🌍 不是所有世界模型都会「怀疑」：RSSM 的两道机制把认知不确定性吃掉了，JEPA 不会
**Not all world models can doubt: how training objective and architecture shape epistemic uncertainty in JEPA and RSSM world models**
*arXiv (2026)*

世界模型预测环境对动作的响应，好在执行前评估候选动作；而这种决策的可靠性上限就是模型的**预测能力**，预测又只在**模型经验范围之内**可信。**认知不确定性（EU）** 正是标记「经验到此为止」的信号。作者做了受控对比：两种范式的代表模型——**LeWorldModel（LeWM，JEPA，无解码器，直接预测下一帧嵌入）** 与 **DreamerV3（RSSM，从循环隐状态重建观测）**——在**十个**模拟视觉控制环境里，对**环境状态施加受控扰动**，并沿模型每一级追到最终 EU 估计（事后 EU：末层 Laplace 与 ensemble）。结论是 **RSSM 在 EU 到达估计器之前，用两道机制把扰动衰减掉了**：(1) **循环更新对上下文做平均**，单帧变化只有**一小部分**进入状态，且要**持续存在**才恢复；(2) **重建目标按像素覆盖面积加权**实体，**小物体可能被训练目标直接丢掉**。**JEPA 两套机制都没有**，变化一路传到不确定性上。这直接造成五类下游任务（从陌生状态检测到带不确定性惩罚的规划）上的差距：**RSSM 的不确定性漏掉了它自己的后验其实已经登记到的偏差**，而 **JEPA 的不确定性报告的正是模型看到的东西**——「能不能怀疑自己」是被**训练目标与架构**写死的，不是通用属性。

📎 arXiv: [2611.34830](https://arxiv.org/abs/2611.34830)

### 🔬 用「透镜」读微调前后的权重差：ΔW 解码后能把后门词排进前十，12 个设定里 11 个成功
**Reading Fine-Tuning Diffs Through Lenses: Model Diffing for Backdoor Detection**
*arXiv (2026)*

微调过程里被植入的后门，往往只改了一小撮权重，行为上难以触发，但**权重差**里应该有痕迹。作者建立一套**基于 token 读出（readout）的统一打分系统**，用来横评**权重、激活、输出**三类 model diffing 方法在**后门检测**上的表现，并把 **J-lens** 及其改进版 **J++-lens** 引入权重与激活方法。实验比较「被后门化的模型」与其**基座模型**：加入 **J++-lens** 后**权重法在所有设定里都变好**，**J-lens** 则改善其在**单层内的排名**。最强的单一方法是 **ΔW J++**——把权重差用**基座模型的 J++-lens 解码**——在 **12 个设定里的 11 个**能把**命名后门的 token** 排进**前十**。但作者也给出了两侧的失效面：**ADL、Diff Mining** 这类输出/激活方法，一旦微调时**惩罚被后门模型在干净输入上给后门词概率**，就会**轻易失效**，而权重法不受影响；反过来，**置换隐单元**或**只训练读残差流的层**能把后门从权重法里**藏起来**，却藏不住 ADL 与 Diff Mining。**没有任何单一方法同时抵抗这两种攻击**——后门检测需要多视角交叉，而不是选一个「最强指标」。

📎 arXiv: [2611.34758](https://arxiv.org/abs/2611.34758)
