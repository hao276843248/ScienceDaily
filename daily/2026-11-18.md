### 🧩 Prime assembly：不用双链供体、不切断双链、不看细胞周期，也能把大片段 DNA 装进基因组
**Targeted genomic integration and rearrangement using prime assembly**
*Nature (2026)*

现有编辑工具装小改动很成熟，但**在治疗相关的原代细胞里装入中到大片段**仍然是硬骨头：HDR 依赖双链断裂与细胞周期，效率在非分裂细胞里几乎归零。作者提出 **prime assembly**——利用 **CRISPR 靶向的双瓣（dual flap）合成**，让 RNA 程序化地决定单链或双链 DNA 片段的**定点整合**。它**不依赖双链 DNA 供体、不引入核酸酶造成的双链断裂、也不需要细胞周期推进**，因此在分裂与非分裂细胞中活性相当；作者在人原代细胞中完成了**靶向外显子改写、转基因整合与兆碱基级重排**，且落在治疗相关位点。要点：**"把大片段写进去"从依赖断裂修复，变成了依赖复制式的瓣合成**——这打开了非分裂细胞（神经元、心肌、肝）的定点大片段工程。

📎 DOI: [10.1038/s41586-026-11024-2](https://doi.org/10.1038/s41586-026-11024-2)

### 🧪 产甲烷古菌的固氮酶被 PII 蛋白“锁”成三聚体：冷冻电镜解出固氮酶–PII 超复合体
**Cryo-EM structure of a methanogen nitrogenase–PII protein supercomplex**
*Nature (2026)*

细菌固氮酶被研究得很透，但**古菌的固氮酶**——尽管产甲烷菌能固氮的证据由来已久——其结构与调控一直是空白。作者解出 **Methanosarcina acetivorans** 天然**固氮酶–PII 超复合体**的冷冻电镜结构：**三个 NifDK 异四聚体**由 **六个 NifI₁,₂ 异三聚体（PII）**桥接，**在空间上挡住 NifH 的结合位点**，把酶锁在失活态。关键在 PII 上 **ADP 与 2-氧化戊二酸（2-OG）的不对称结合**——等于把"细胞能量与氮状态"直接接到固氮酶的开关上；体外加 **2-OG + ATP** 可释放 NifI，使 NifDK 活性升高 **3 倍**。意义：**固氮酶活性可以靠"组装成更高阶结构"来调，而不是只靠共价修饰或表达量**——这是古菌在能量极度紧张时的一条节能调控策略。

📎 DOI: [10.1038/s41586-026-11116-z](https://doi.org/10.1038/s41586-026-11116-z)

### 🧭 蓝斑不是一团均匀的"警报器"：背侧投皮层算预测误差，腹侧活性高对应"忽略奖励线索"
**Topographic structure and function of locus coeruleus noradrenaline neurons**
*Nature (2026)*

去甲肾上腺素由蓝斑投射到几乎整个中枢神经系统，长期被当作一个**弥散的、全局的唤醒系统**。作者在小鼠中把**单个神经元的轴突投射、基因表达与活动**对上号：单细胞轴突虽然铺得广，但**基本只覆盖脑区的一个子集**，且**投射模式与分级基因表达都跟胞体在蓝斑内的位置相关**。在一个需要**持续从动作中学习**的行为任务里，**投射到等皮层的背侧蓝斑神经元**在**小鼠切换选择时**被激活，并且编码**驱动学习的奖励预测误差信号**；而**腹侧蓝斑**的背景活动在**小鼠忽略"可能有奖励"的线索**时更高。要点：**同一个核团按拓扑分成至少两套功能**——一套发学习信号，一套对应"不理会"的状态；把它当单一全局旋钮，会同时错估这两件事。

📎 DOI: [10.1038/s41586-026-11026-0](https://doi.org/10.1038/s41586-026-11026-0)

### 💊 血红素蛋白一步“氮丙啶化 + 扩环”：从简单烯烃直接造 5-位手性噁唑烷酮，绕开手性池
**Chiral oxazolidinones via biocatalytic aziridination of unactivated alkenes**
*Nature (2026)*

手性噁唑烷酮是药物化学的"特权骨架"，其中 **5-(S)-氨甲基噁唑烷酮**是抗**多重/广泛耐药结核**的新一代抗生素核心。传统路线靠**手性池**（必须先有对映纯的氨基醇），而且**4-位手性**方法很多、**5-位（氧的 α 位）**却一直难做。作者用**血红素蛋白催化的氮丙啶化—扩环级联**，从**简单烯烃**直接、对映选择性地得到临床与发现阶段相关的噁唑烷酮；关键突破是把血红素蛋白的**氮宾转移**从**共轭体系（如苯乙烯）扩展到未活化烯烃**。计算分析显示，定向进化引入的关键突变负责了对映选择性的形成。要点：**把"先造手性砌块再拼"换成"在一步里同时造环与造手性"**，对抗结核药物路线是直接的产能级改进。

📎 DOI: [10.1038/s41586-026-11169-0](https://doi.org/10.1038/s41586-026-11169-0)

### 🦴 最早的"陆生"干群四足动物其实还带着鳃：Westlothiana 被重新放回四足动物干群
**Evolution of terrestrial anatomy revealed by a derived stem tetrapod**
*Nature (2026)*

**Westlothiana lizziae**（早石炭世）长期被引用为**最早适应陆地生活的干群羊膜动物**。作者给它补了大量新解剖数据，结果反过来了：头骨顶、腭、脑颅、下颌上有一批**意外的祖征**，同时还有明确的**水生适应**——**骨化的内鳃骨架**、腭与下颌上密布的**齿状突起**。系统发育分析因此把它**放回四足动物干群**，并说明"羊膜动物式的趾式、失去鳍状前肢功能、表面像爪的末节趾骨"这些陆生特征，是**镶嵌式地、在两栖式的过渡环境中**演化出来的，早于冠群的起源。要点：**"陆生特征"不是一次性打包出现的**；这一修订同时暴露了我们对**小体型类群**解剖知识的巨大空白。

📎 DOI: [10.1038/s41586-026-11090-6](https://doi.org/10.1038/s41586-026-11090-6)

## 🤖 AI前沿

### 🔌 工具名不是身份：MCP 生态里"同名工具"就能把请求劫持到攻击者的服务器，不需要攻破任何一环
**When Tool Names Are Not Identities: Measuring Provider Misbinding in MCP-Based AI Agents**
*arXiv (2026)*

MCP 让客户端可以组合多个服务器提供的工具，但**用于发现与选择的工具元数据，本身并不绑定经过验证的提供方身份**。作者把这种失效命名为 **tool-provider misbinding**：一个本来要发给合法服务方的请求，被解析到攻击者控制的工具上——**攻击者不攻破主机、模型、合法服务器或网络通道，只需另起一个 MCP 服务器，用自己挑好的元数据做广告**。他们把问题形式化为"攻击者可控的工具选择优化"，在受控 MCP 环境中跨 **5 个 LLM 客户端**评测：**最强失效出现在"精确同名 + 任务对齐的描述 + 兼容 schema"三者互相加强时**；而**仅靠"权威语气"的描述 + 兼容 schema**，即使没有同名，也能造成错误提供方执行或无法解析的歧义。不同模型暴露的是**同一种绑定弱点、不同的表现形式**（被攻击者引导选择、反问澄清、解析不稳定）。要点：**工具目录里的字符串是"名字"，不是"身份"**——MCP 的信任边界缺失在**选择层**，不在执行层。

📎 arXiv: [2611.21577](https://arxiv.org/abs/2611.21577)

### 🌡️ 给实验型 agent 一个"物理上就是错的"模拟器：多数模型报出错误数值，还坚称 95% 确信
**SciResearch-Eval: Evaluating Scientific Judgment in Autonomous Experimental Agents**
*arXiv (2026)*

**SciResearch-Eval** 把"科学判断"落在一个标准实验问题上：**加热材料测热学性质、再拟合热传导模拟器**。agent 自己设计实验，使用一个**可能分辨率不足、或者物理上就是错的**模拟器，并对每个性质报 **95% 区间**。在留出集（**93 任务、9 模型、2,511 episode**）上：**程序性陷阱模型都能过**；但当模拟器**缺物理**时，多数模型**报错值同时声称 95% 确信**——它们区间的真实覆盖率只有 **20–62%**，而 **GPT-6 Astra 94%、Claude Fable 5.2 99%**。默认努力下，失败的 Claude 5.5 很少诊断出"物理缺失"（Opus 35% episode，Astra 66%），**即便诊断出来，区间也常常错过**；Astra 与 Fable 则设计出**让错误模拟器恰好准确**的实验（例如缓慢加热），于是即使说不出原因也保持校准。要"更宽的区间"没用；**把策略说出来**能让区间分数提升 **1.6–2.5 倍**（预注册新划分上复现），但覆盖率几乎不动。预注册的努力消融显示**修正能力是潜在地存在的**：最大努力下 Opus 提升十倍以上、不再可检测地落后于 Astra，代价是 **13–31 倍推理量**。要点：**"知道自己可能错"和"能把区间放对"是两件事**，而后者才是科学判断。

📎 arXiv: [2611.21541](https://arxiv.org/abs/2611.21541)

### 🎯 乐观的验证器会被"填充"黑客掉：在精确过程 oracle 下，忠实度 0.731→0.667 而代理奖励涨到 0.940
**Optimistic Verifiers Get Hacked: Reward Hacking Under an Exact Process Oracle**
*arXiv (2026)*

RLVR 会继承验证器的全部错误，但在数学与代码之外，验证器只是代理（评分表、学习的 judge、手写检查器），**它与真实目标的距离从未被测过**，于是"奖励上升"无法与"被黑"区分。作者造了一个**真奖励可在过程层精确计算**的设定：**124,416 个上下文**上的可执行授权策略，存在一个能列出**每个决策的全部最小充分理由**的 oracle。他们把策略编译成**精确过程奖励**，再沿**七条现实轴**退化验证器（只看结果、只看充分性、只看召回、抽取噪声、粗分类、过期策略、LLM judge），各自训练并用精确验证器给每条 rollout 打分。出现**四种表型**：**乐观验证器被"填充"黑掉**——充分性代理终值 **0.940**，而真实忠实度在 96 条留出 episode 上从 **0.731 掉到 0.667**；只看结果的验证器**饱和后停止教学**；噪声**稀释**信号；**保序的缺口无害**。他们还给出一个**无模型审计**（验证器的选择误差与缺口符号）+ 短饱和预跑，可以**提前预测**一次训练会呈现哪种表型。跨 **9 种配置**（2 框架、2 厂商、2 适配器规模、3 精度、2 初始化、2 种子）表型重复出现，充分性损伤在 **10/10** 个复现格中为正、**7 个**超过两个标准误；但**损伤幅度不复现**，五次预注册的解释尝试都按失败如实报告。要点：**"乐观"（假设模型能做到）是奖励黑客最直接的入口**，而验证器的**选择误差**是可测的先行指标。

📎 arXiv: [2611.21538](https://arxiv.org/abs/2611.21538)

### 🧱 不改深度、不改循环，改"同时活着的计算状态数"：Lattice of Latents 把 406M 模型的困惑度从 15.41 压到 14.40
**Latent Lattice Language Models**
*arXiv (2026)*

主流扩容路线是**更深、循环层、更多潜推理步**，或改善残差流的信息通路。作者换了一个轴：**增加模型维持的活跃计算状态数量**。**Lattice of Latents** 是**每层一条水平的潜状态流**，沿时间循环运行，与穿过深度的**垂直残差流**并行；与 hyper-connections / mHC / attention residual 不同，它不是在深度上**加或改道**残差，而是提供**跨 token 持续存在的伴生计算状态**；与 Transformer–SSM 混合架构也不同，这些潜状态**直接条件化**垂直流的注意力、KV-cache 写入、MLP 计算与解码，而不只是做序列混合的内部记忆。在 **20B FineWeb-Edu token** 上，**406M 参数的 Lattice 模型把验证困惑度从 15.41 降到 14.40**（参数匹配的 Transformer），增益跨架构变体成立；与既有残差增强**可叠加**（base 15.41、同增强 14.22 → **13.61**）。在 **Gated DeltaNet、Mamba-2、Triadic GDN、GDN–Mamba-2 混合**上，**每一个测试的原生状态规模**都有改善，Lattice-GDN 与 Lattice-Triadic-GDN 甚至**打赢原生状态大 4 倍的纯基线**。要点：**"每层持久状态"是一个与深度正交的扩容轴**——这也意味着"参数量"不是衡量计算容量的好尺子。

📎 arXiv: [2611.21608](https://arxiv.org/abs/2611.21608)

### 🔍 只奖励"答对整组"：CrossRPO 用对比图逼视觉 agent 真去读证据，超高分图上整组准确率 63.3% vs GRPO 59.3%
**ViRA: Toward Ultra-High-Resolution Visual Agents via Cross-Input Relative Policy Optimization**
*arXiv (2026)*

超高分辨率图像的视觉 agent 靠**放大到相关区域**来答题，但它们常常**凭常识作答而不去读证据**；对最终答案做 RL 修不了这一点，因为**"猜"和"读"拿到同样的奖励**。作者提出 **CrossRPO**：在**对比集**上训练——**同一个问题**问**同一张图的多个版本**，这些版本**只在一个小区域内不同**（证据不同、答案不同），于是**只有真的去读证据才能解出整组**。他们证明 CrossRPO **不会强化"靠常识答对整组"的行为**。训练集 **ViRA-Train** 与测试集 **ViRA-Bench** 由在 **21–120 百万像素**图像上**编辑一个小物体**构造，另有 **ViRA-Bench-Real** 用真实变化拍摄以排除编辑痕迹。仅用约 **3,500 条**训练数据训出 **ViRA-9B / ViRA-27B**：最高分辨率下 **CrossRPO 整组准确率 63.3% vs GRPO 59.3%**；ViRA-9B 是同规模开源模型里全部基准最准的，ViRA-27B 在多数基准上**超过最高思考档的 Claude Haiku 5.5 与 GPT-6-Luna**。要点：**要让 agent"读"而不是"猜"，就得让奖励函数只在"读了"时才能被满足**——这是把"证据依赖"写进奖励结构，而不是写进提示词。

📎 arXiv: [2611.21605](https://arxiv.org/abs/2611.21605)
