### ☀️ 把「带边」从钙钛矿里延展到界面：全共轭甲脒类分子做电子耦合异质结，反式电池认证 27.96%、叠层认证 34.71%
**Band-Edge-Extended Heterointerfaces for Perovskite Solar Cells and Tandems**
*Nature (2026)*

钙钛矿电池的效率瓶颈已经从「吸光层本身」移到**吸光层/电子传输层（ETL）界面**：传统铵盐类界面修饰剂与钙钛矿表面的电子耦合很弱，往往还顺手插进一道电子抽取势垒。作者用一族**含杂原子、全共轭的甲脒（formamidinium）界面调控分子**，做出**带边延展的共轭异质界面**——在钙钛矿/ETL 界面建立**离域电子连通**，把界面非辐射复合压下去。读数是**反式结构认证 PCE 27.96%、稳态输出 27.84%**，1-sun 最大功率点连续跟踪 **2000 h 后仍保留 >95%** 初始效率（ISOS-L）；同一策略搬到**单片钙钛矿–硅叠层**得到**认证稳态 34.71%**。要点：**界面修饰从「钝化缺陷、插一层绝缘分子」改成「把 π 电子云接到传输层的带边上」**——界面不再是势垒，而是能带的延伸段。

📎 DOI: [10.1038/s41586-026-11427-1](https://doi.org/10.1038/s41586-026-11427-1)

### 📍 不信任设备也能证明「你在哪」：Bell 检验式量子位置验证首次实验演示，一维定位比最好的非远程经典方案小 2.47 倍
**Quantum position verification with remote untrusted devices**
*Nature (2026)*

证明「这条信息确实来自某个位置」是导航、授时、认证与关键基础设施的共同前提，但经典方法可被中继/伪造攻破。已有量子位置验证（QPV）方案要么**依赖可信的量子硬件**，要么**需要量子计算机 + 对对手算力的界**。作者提出并实验演示了**Bell 检验式 QPV 协议**：安全性只依赖一次**无漏洞 Bell 检验观测到的关联**，因此是**设备无关**的；实验在网络中对抗**每次试验前仅弱纠缠**的对手。结果：一维定位精度比最好的（必然非远程的）经典定位协议**小 2.47(2) 倍**；与延迟相同的经典协议相比，**定位体积小 4.53(5) 倍**，构成可证的量子优势。协议本身**容忍损耗**、可抗自适应对手。要点：**「位置」这种几何事实可以被转成一种非局域关联来验证**——安全性来自物理定律，不来自你相信对方那台机器。

📎 DOI: [10.1038/s41586-026-11247-3](https://doi.org/10.1038/s41586-026-11247-3)

### 🩸 一块只靠血糖供电的「人工神经免疫轴」：无电池、闭环迷走反射，把 1 型/2 型糖尿病大鼠的血糖调回正常
**A glucose-powered artificial neuroimmune axis for metabolic control**
*Nature (2026)*

靶向自主神经的电疗设备能抗炎，但**缺少「代谢内感受」这一路反馈**，所以无法把免疫—代谢稳态一起拉回来。作者做出 **NeuroAxis**：一个**完全由内源葡萄糖供能**（无电池、无无线供能）的闭环植入器件，用**带代谢内感受反馈的闭环神经调控**模拟**迷走反射**。在 **1 型糖尿病大鼠**中促进**产胰岛素 β 细胞恢复**并降低炎症免疫反应；在 **2 型糖尿病大鼠**中驱动**巨噬细胞重塑**、降低全身慢性炎症；两个模型都恢复了糖耐量、改善胰岛素敏感性、把血糖归一，且**停止治疗后疗效仍持续**。要点：**把「供电」与「感知」合并到同一个代谢量上**——设备的能量来源就是它要调节的变量，这既省掉了电池，也天然给了它内感受通道；从「替代某个器官的功能」转向「重建一条器官间的通信回路」。

📎 DOI: [10.1038/s41586-026-11251-7](https://doi.org/10.1038/s41586-026-11251-7)

### 🔦 超辐射也能出「梳」：驱动自旋系综 + 片上超导腔里连续波转为周期性脉冲超辐射，并做出微波/光双通道频率梳
**Observation of tunable superradiant frequency combs**
*Nature (2026)*

超辐射来自发射体的**集体量子干涉**，长期被当作获得超稳连续辐射的途径，但**在时域上工程化超辐射**（做出周期性脉冲源或频率梳）几乎没被探索过。作者研究**驱动自旋系综与片上超导谐振腔耦合**的非平衡多体动力学，发现从**连续波超辐射到周期性脉冲超辐射的动力学相变**；并用**驱动—耗散腔 QED 模型**定量解释：脉冲相来自**相干性增长、无序、耗散三者互相稳定**的周期性重复自旋动力学。进一步，在**同时具备光学与微波跃迁的稀土离子自旋体系**中，得到**相位同步、双通道（微波 + 光学）超辐射频率梳**。要点：**「集体辐射」被赋予了时间结构**——这既给出原子型频率梳源，也把「周期性脉冲超辐射」与**连续时间晶体的涌现**连到同一个机制上。

📎 DOI: [10.1038/s41586-026-11289-7](https://doi.org/10.1038/s41586-026-11289-7)

### 🌳 亚马逊并不常绿：70.0% 的区域落叶比长新叶早至少 3 个月，把落叶写进模型可改善 79.9% 区域的生产力季节曲线
**Widespread deciduousness reveals diverse Amazonian phenological strategies**
*Nature (2026)*

亚马逊长期被建模为**常绿生态系统**，这个假设把叶片物候的细尺度差异抹平了，也就限制了碳水循环对气候变化的可预测性。作者用 **10 m Sentinel-2 观测 + 机器学习**，在全流域发现**普遍且空间结构化的季节性落叶**：**70.0% 的亚马逊**「落叶」比「长新叶」早至少 **3 个月**，形成**落叶与绿度季节性的显著异步**，其余区域接近同步。归因上，**水文气候**解释 **51.6%** 区域的异步，**土壤属性 33.2%**、**光照 15.2%**。把**落叶约束的叶片周转与叶龄人口学**写进生态生理模型后，**79.9% 区域**的模拟总初级生产力与卫星光合季节性的吻合度提升。要点：**「绿度」不等于「叶量」**——卫星看到的绿是叶龄与叶质的混合信号；把落叶当独立过程建模，才能改对碳通量的季节相位。

📎 DOI: [10.1038/s41586-026-11284-y](https://doi.org/10.1038/s41586-026-11284-y)

### 🌡️ 别只喂「完美答案」：让冻结的预训练模型当高温噪声教师，SFT 平均相对提升最高 21%
**Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching**
*arXiv (2026)*

后训练数据总是远小于预训练数据，于是 SFT 容易过拟合、并把数据分布的**尾部整体遗忘**。作者提出 **Ambient SFT**：把一个**冻结的预训练模型当噪声教师**，要求微调模型在**粗粒度层面**与之匹配——具体是让后训练模型的**高温版本条件分布**去匹配预训练模型的**高温版本条件分布**。温度超参数就是「对预训练模型的信任度」：**T→∞ 退化为普通 SFT，T=1 退化为知识蒸馏**。在**领域适配、指令微调、推理**三类任务上均优于标准 SFT，**平均相对提升最高 21%**。要点：**「不完美但有分布信息」的预测本身就是数据**——不是让学生复制教师答案，而是约束学生别把教师已经知道的分布尾部丢掉。

📎 arXiv: [2611.23229](https://arxiv.org/abs/2611.23229)

### 📉 编码榜分数更高，并没有让人多干活：Fable 5 被禁 19 天的自然实验，7 日合并率仅 +1.4 个百分点且不显著
**Higher-Scoring Coding Models Did Not Get More Work Done**
*arXiv (2026)*

新编码模型都拿 benchmark 分数做卖点，但**「分数更高是否等于真实工作产出更多」从未被检验**。2026-06-12 美国出口管制指令禁止访问 Claude Fable 5 共 **19 天**，大部分原用户切到 SWE-Bench Pro 上低 **11 分**的 Opus 4.8——人与项目不变、只有模型变了，构成自然实验。作者追踪 **297 名** Fable 5 用户在禁令前/中/后的 GitHub PR，用 **8,908 名**全程留在 Opus 4.8 的开发者作对照，并额外比较 2026 年五次模型升级（**1,208 人、15,442 个 PR**），拟合带开发者与日期固定效应的**双重差分**。结果：能用 Fable 5 只让 PR 的 **7 日合并率提高 1.4 个百分点**（[−1.4, +4.3]，不显著）；五次升级的加权均值是 **−0.9 个百分点**（[−1.9, +0.2]，五个估计全为负）；每周合并 PR 数 **+2.4%**（[−4.9, +10.2]）。要点：**benchmark 分数是「能力刻度」，不是「产出刻度」**——真实工作里模型只是流水线一环，瓶颈常在人、评审与需求侧；评估一个编码模型该看端到端交付，而不是解谜通过率。

📎 arXiv: [2611.23216](https://arxiv.org/abs/2611.23216)

### 🪪 跨组织 agent 需要「护照」：PKI + 零信任 + 远程证明把攻击遏制率从 43% 提到 84%，每次请求开销约 174 微秒
**Agent Trust Infrastructure (ATI): A Federated Identity, Trust, Attestation, and Accountability Architecture for Cross-Organization Autonomous AI Agents**
*arXiv (2026)*

Agent 跨组织调用工具、与别家运营的 agent 交互时，现有框架只管规划与协调，**没有共同机制验证对方身份、执行完整性与授权**。作者提出 **ATI**：基于 **PKI + 零信任架构 + 远程证明**，用**对等的组织级证书机构（AgentCAs）**建立联邦信任，**不需要共享根**；执行前验证 agent 证书、核验**已批准的模型/工具/系统提示配置**，并通过三道策略检查强制授权。实现为**外挂式安全执行层**，不改各框架底层模型。评测在 **8 个组织、6 个 agent 框架**（各 5 agent 团队）的模拟联邦中进行，安全实验涉及 2 个组织、**14 个攻击场景 + 6 个良性任务、5 个 agent 模型、5 种攻击变体 × 3 次重复**，由评审模型打分。全部机制开启后，**攻击遏制率 43%→84%**（在 11 个全配置一致评测的场景上是 40%→80%），**每请求开销约 174 微秒**；身份与请求用 IETF **WIMSE** 工作负载令牌、完整性用 **Entity Attestation Token**。要点：**agent 互操作的信任边界要建在「配置 + 身份」而不是「自然语言声明」上**——先证明你跑的是被批准的那套模型/工具/提示，再谈你能干什么。

📎 arXiv: [2611.23202](https://arxiv.org/abs/2611.23202)

### 🎭 「偏见注意力头」测到的可能只是提示词本身：与「盲标响应长度图」相关 ρ=−0.95，同一提示内标签/长度/受保护词共线 φ=0.95，抽掉任何头组都没降低不公平率
**What Does a Bias Head Measure? Non-Identifiability in Head-Level Bias Attribution**
*arXiv (2026)*

把大模型的社会偏见定位到**单个注意力头**、再用**消融**去掉，这类方法的验证一直是「消融后公平性指标变好」，却**从未证明「选出这些头的统计量本身测的是偏见」**。作者在 **Qwen-2.5-7B-Instruct** 与 **Llama-3.1-8B-Instruct** 上做审计：头图与**盲标签的响应长度图**相关达 **ρ=−0.950 / −0.768**；进一步做一个**打破长度—标签耦合**的干预，发现同一提示下**响应长度只解释该统计量 1% 的方差**，真正解释它的是**提示身份（64%）**，且排序对长度**非单调**。但在任一固定提示内，**公平标签、响应长度、是否含受保护群体 token 三者共线（φ=0.95）**——部分由标注规则定义决定，于是**任何观察式分析都无法把头图归因于其中任何一个**，这一族方法也都没做过能区分的实验。实质结论独立成立：两个模型、两种参考读法下**偏见选择性都不是晚层集中**；**所测任何头组被消融后都不降低不公平率**，而其**补集（在对侧标签上评分）可靠地摧毁拒答行为（p=2.7×10⁻⁵）**——说明流水线在这个尺度上确实能测出效应。要点：**「定位」需要可辨识性，更需要干预实验**；否则解释出来的只是提示词结构，而且消融掉的可能是能力而非偏见。

📎 arXiv: [2611.23218](https://arxiv.org/abs/2611.23218)

### 👁️ 视觉模型的危险不在「问它坏问题」，而在「让它看懂一个场景」：场景态输入 ASR 45.6–72.3%，S3TA 平均 71.2%
**Reading Scene States: Uncovering Safety Failures in Vision-Language Models**
*arXiv (2026)*

视觉语言模型（VLM）可以**在没有明确请求有害目标的情况下**，仅凭解读画面事件就给出有害协助——作者把这种失效命名为**场景态（scene-state）安全漏洞**，并构建 **SceneSafetyBench**：**375 个图文问答对**，覆盖**初始 / 中间 / 终极**三种场景态与**五种视觉呈现方式**。八个 VLM 上，场景态输入触发有害协助的**攻击成功率 45.6–72.3%**。机制侧，对三个模型做逐层对比发现场景态输入**在安全相关信号剖面最接近二维码类图像**，但**晚层读出更低、生成期信号动态不同**。把漏洞变成系统攻击的 **S3TA** 把有害目标翻译成场景态、**逐对独立提问再拼装答案**；在 **MM-SafetyBench 七个类别、八个开源与商用 VLM** 上，模型平均 **ASR 71.2%，比最强基线高 6.1 个百分点**，而**文本侧过滤器与视觉审核只提供有限保护**。要点：**安全对齐只盯「输入内容」是不够的，模型从画面推断出的事态本身就是一条绕过通道**——要防的是**由场景推理得出的协助**，不是画面里出现了什么。

📎 arXiv: [2611.23206](https://arxiv.org/abs/2611.23206)
