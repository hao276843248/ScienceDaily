### 🧵 用 1D 纳米带「原子级编织」出合成 2D 量子材料
**Synthetic 2D quantum materials from atomic weaving of 1D nanoribbons**
*Communications Physics (2026)*

低维**范德华（vdW）自下而上组装**是设计定制量子性质材料的灵活路径，但此前主要停留在**把 2D 材料层层堆叠**，用其它低维构筑单元做组装仍基本未被探索。作者提出一种**「原子级乐高」构建策略**：用 **1D 纳米带**去组装 2D 材料，在**晶格几何、堆叠方式与边缘构型**层面嵌入结构级设计自由。以**石墨烯纳米带（GNRs）**为原型，他们发展出一套通用的**编织方法**，把一维带互相交错织成二维结构，为在原子尺度「织」出具有可调量子性质的合成材料提供了新途径。

📎 DOI: [10.1038/s42005-026-02936-6](https://doi.org/10.1038/s42005-026-02936-6)

### 🌀 亮激子与暗激子共同驱动的极化激元波导自旋流
**Spin currents in polariton waveguides driven by bright and dark excitons**
*Nature Materials (2026)*

**光学自旋霍尔效应**本可把线偏振光分离成四个圆偏振域，但其机制依赖非简并的横电/横磁模式，对**非相干光致发光无效**。在过渡金属硫族化物单层里，**亮激子**有面内电偶极与强振子强度，**暗激子**则有面外偶极。作者把 **WS₂ 单层嵌入波导微腔**，让亮激子与光子模式**强耦合**形成**激子—极化激元**；在非共振泵浦下，**暗激子被大量布居**并同时馈入横磁型与横电型极化激元模式（各自带面外电场分量），从而在波导中驱动**自旋流**。该工作把此前对非相干光失效的自旋输运机制，拓展到了可在波导中主动利用的激子—极化激元平台。

📎 DOI: [10.1038/s41563-026-02782-5](https://doi.org/10.1038/s41563-026-02782-5)

### 🛡️ 恒激发（CE）稳定子码在相干噪声下的容错量子纠错框架
**Fault-tolerant quantum error correction for constant-excitation stabilizer codes under coherent noise**
*npj Quantum Information (2026)*

**集体相干（CC）噪声**无法被常规随机噪声模型刻画，给**容错纠错（FTEC）**带来难题；**恒激发（CE）码**虽天然免疫 CC 错误，却一直缺乏在**线路级噪声**下运行的容错框架。作者基于**双轨（dual-rail）级联**为 CE CSS 码建立 FTEC 框架：他们发现常规**横向 CNOT 会破坏 CE 约束**，于是发展出**保持 CE 的逻辑 CNOT 门**，以及用**零控非门（zero-controlled NOT）**与**CE 兼容辅助态**改造的 **Shor 型与 Steane 型校验子提取**方案；并开发了**可同时追踪随机与 CC 噪声的扩展稳定子模拟算法**。在该框架下他们识别出一批小距离 CE CSS 码，并给出如 **[[14,1,3]]** 码的具体表现，为在相干噪声主导的真实硬件上运行此类编码提供了一条可行路线。

📎 DOI: [10.1038/s41534-026-01401-0](https://doi.org/10.1038/s41534-026-01401-0)

### 💥 扭转冲击波：用螺旋纳秒脉冲做弹道式微粒操控
**Twisted shock waves enable ballistic microparticle manipulation**
*Communications Physics (2026)*

在液体中操控微观物体对微流控与快速流体过程研究都很重要，但传统**光镊/声操控主要依赖持续施力**，难以触及**纳秒尺度的脉冲式动力学**。作者证明：把**螺旋形纳秒激光脉冲**聚焦进薄液层，可产生带**可调角动量**、峰值压强达**吉帕（GPa）量级**的**扭转冲击波**；**时间分辨阴影成像**与**二维流体动力学模拟**独立给出了对螺旋几何一致的依赖关系，说明角动量可由激发形状控制。他们进一步展示一颗 **10 微米聚苯乙烯微粒**能在纳秒时标上做**环状弹道运动**，把冲击波从「破坏性现象」变成可编程的**微纳操控工具**。

📎 DOI: [10.1038/s42005-026-02935-7](https://doi.org/10.1038/s42005-026-02935-7)

### 🧠 可重构仿脑离子电子网络：把「多模态响应」当训练资源
**Multimodal training in reconfigurable brain-inspired iontronic networks**
*npj Unconventional Computing (2026)*

作者提出一种受脑启发的**离子电子（iontronic）物理计算**方案，作为传统数字神经网络的替代：在**微流控网络**中，节点由**填充电解质的锥形通道**相连，充当**忆阻性离子电子突触**，其电导既能被通道几何调，又同时**依赖电学、化学与机械信号**。他们利用这种**多模态响应性**，让小型网络被训练完成**非线性任务**：**前向传播由离子弛豫物理地完成**，训练则把这种物理演化与**数值梯度下降**结合，理论上可完成输入—输出映射与含偏置的线性回归。更关键的是，电路可**通过调节被重构**去执行不同目标——把「物理器件的多物理场耦合」从干扰变成了**可编程的计算自由度**。

📎 DOI: [10.1038/s44335-026-00105-0](https://doi.org/10.1038/s44335-026-00105-0)

## 🤖 AI前沿

### ⚡ 潜在稀疏注意力（LSA）：把超长上下文注意力做成次二次
**Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention**
*arXiv:2610.42147 (2026)*

智能体工作流正走向**长时程任务**（如开放式科研），越来越依赖**超长上下文**，但在 **100 万 token 以上**时全注意力代价高得离谱。稀疏注意力让专用 **indexer** 选出一部分 key，但现有索引要么在上下文长度上**仍是二次代价**，要么在超长尺度下**掉精度**。作者提出 **Latent Sparse Attention（LSA）**：把 key **在学习到的潜在空间里分层聚类**，让 query 去给**簇的层级打分**而非逐个 key 打分。两个变体 **D-LSA（蒸馏式，可套到预训练模型）**与 **N-LSA（仅用下一 token 损失原生训练）**在 **GLM-5.3-FLASH（QWEN-3.8-27B）**、**10M token** 上：D-LSA 单层注意力相对原稀疏注意力（全注意力）**预填充提速 22.7×（72.4×）、解码 4.6×（42.5×）**且精度相当；N-LSA 在 128k token 下以 **1.6× 单层训练加速**追平全注意力精度。

📎 arXiv: [2610.42147](https://arxiv.org/abs/2610.42147)

### 🤖 RoboArchitect：让编码模型自动设计机器人智能体的「外骨架」
**RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory**
*arXiv:2610.42141 (2026)*

已有研究表明，**冻结的机器人策略**放进一个**agent harness（外骨架）**里会表现好得多——由控制代码决定何时查询策略、调用视觉工具或直接驱动机器臂；但这些 harness 如今**全靠手工搭建**，每换一个机器人或基准就得重设计。作者把 **harness 设计自动化**：在 **RoboArchitect** 中，一个**编码模型观察机器人 rollout、诊断失败、迭代修改**围绕冻结策略的 harness，优化用一批 episode、评估用**留出场景与任务**。**不更新任何模型权重**的前提下，多个基准与策略上平均成功率从未见场景 **9.7%→43.3%（4.5×）**、未见任务 **12.7%→40.2%（3.2×）**；harness 还能**演化出自己的持久记忆**（如有效抓取深度）带到后续决策。作者由此主张：机器人操作里相当可观的提升空间，其实藏在**可自动优化、免微调**的外骨架中。

📎 arXiv: [2610.42141](https://arxiv.org/abs/2610.42141)

### 🔐 SecPO：给提示注入防护补上「理论上有原则」的对抗训练
**SecPO: Principled Adversarial Training for Prompt Injection Security**
*arXiv:2610.41998 (2026)*

**提示注入**（来自邮件、文档、网页等不可信数据的指令操纵智能体）被列为 AI 智能体的头号威胁；即便是防护最佳的 **Meta-SecAlign**，在**自适应攻击**下攻击成功率（ASR）仍逼近 **100%**。作者指出一个根因：**DPO 把模型锚在一个未设防的参考模型周围**，而后者本身不安全；他们观测到那个**理想化的「注入不变、保住效用」的 oracle 参考模型**的输出分布在训练中其实是**可近似获取的**，由此导出理论上更干净的 **SecPO 损失**。此外他们用**高效对抗训练（AT）管线**合成**强注入输入（best@240）**来训练。结果：相比 Meta-SecAlign，AT 在三种 SOTA 自适应攻击下把 ASR **降 1.5–14.5×**，SecPO 损失再**额外降 2.4–4.6×**；在智能体流程中，**SecPO + AT 的 Qwen3.6-27B** 在 AttackerMovesSecond 攻击下 AgentDojo ASR@800 仅 **8.8%**（对比 78.8%），且九项基准上**良性效用无明显下降**。

📎 arXiv: [2610.41998](https://arxiv.org/abs/2610.41998)

### 🧩 CRoS：用「打乱思路顺序」度量推理的因果性，兼顾准确与忠实
**CRoS: Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithfulness**
*arXiv:2610.42054 (2026)*

**可验证奖励强化学习（RLVR）**已成训练语言模型推理的标准做法，但它**只看最终答案对错**，不保证**思维链（CoT）对答案有因果贡献**。现有因果性度量靠**扰动 CoT**（删步、注入错误）后看答案变化，可这些扰动**必然改变了每一步的信息**，于是高分可能只反映「对信息变化的敏感」而非真因果，用作奖励还会诱发**更空洞的 CoT、更少探索与自我纠错**。作者提出 **CRoS**：只**打乱推理步骤的顺序、不改内容**，从而保留每步信息、隔离出真正的因果性。在 **Reasoning Gym + Gemma-3-4B** 上，CRoS 在**域外准确率**（五个未见解逻辑/博弈数据集 **46.8% vs 最强基线 43.8%**）、**CoT 质量**（CoT-Pass@K 从 K=1 到 128 平均 **43.4% vs 41.4%**）与**忠实度**（提示承认分 **34.0% vs 20.2%**）上全面领先。

📎 arXiv: [2610.42054](https://arxiv.org/abs/2610.42054)

### ⚖️ 全 AI 招聘链的偏见：模型选择本身会「刷掉」合格候选人
**AI evaluators favor job applications written by certain AI models, independent of candidate quality**
*arXiv:2610.41866 (2026)*

求职者越来越用大模型写求职信，雇主又用大模型来筛——在这条**全 AI 链路**里，作者追问：**所选模型会不会独立于候选人资质、影响录用结果**？他们设计了**多模型审计框架**：**11 个 LLM 写作智能体 × 9 个 API 评测智能体**，覆盖 **10 个职位、每职位 50 名候选人**。四个发现：① 存在一个**稳定的「生成偏好层级」**——评测方对写作模型的接受度形成全局排序，**本地部署模型无论许可与否都被系统性看低**，并叠加**自我偏好偏差**（评测方偏爱自家输出）；② 不同评测模型引入的**偏倚程度差异很大**，为更公平的筛选设计提供指引；③ 该层级有**可量化的竞争后果**：在最不利配对下，25 名合格候选人中约有 **1.8 名**纯粹因**模型错配**被筛掉；④ 统一机制可解释上述现象——偏好与自我偏好都源于**各个模型对特定文体线索的倚重**、以及评测方对这些线索（常是**一致地**）的奖惩。

📎 arXiv: [2610.41866](https://arxiv.org/abs/2610.41866)
